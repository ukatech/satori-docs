# 里々独自のイベントと文

辞書に書くと、里々が特定のタイミングで実行する文です。

| 名前 | 実行されるとき | 結果の扱い |
|------|----------------|------------|
| `＊初期化` | `satori_conf.txt` を読み込んだ直後（最初） | 結果は使われない。システム変数の設定を書く |
| `＊セーブデータ` | セーブデータの読み込み | 変数の復元（里々が自動で書き出したもの） |
| `＊OnSatoriLoad` | 辞書の読み込みが終わったとき | 結果は使われない |
| `＊OnSatoriBoot` | 辞書の読み込みが終わったとき | 最初の `OnBoot` / `OnGhostChanged` で返す |
| `＊OnSatoriClose` | `OnClose` / `OnGhostChanging` のとき | 空でなければ、終了時の応答にする |
| `＊OnSatoriUnload` | アンロード時のセーブの直前 | 結果は使われない |
| `＊OnSatoriSecondChange` | 秒ごと。ほかに何も喋らなかったとき | 空でなければ、応答にする |
| `＊COMMUNICATE該当なし` | 話しかけられたが、該当する文がなかったとき | 応答にする |

## OnSatoriBoot

`＊OnSatoriBoot` の結果は、最初の起動のイベントの応答として使われます。これを使うと、`OnBoot` が届く前に、ゴーストの状態に応じた挨拶を組み立てられます。結果が「中身のない応答」になった場合は使われません。

## OnSatoriSecondChange

`OnSecondChange` のたびに、そのほかの応答（タイマ、ランダムトーク）が何も生まれなかったときだけ呼ばれます。辞書側で独自の自動発話の仕組みを作るために使います。結果が空でなければ、ランダムトークと同じ扱いで応答になります。

## 自動的に用意される名前

- `＊OnTalk`: ランダムトーク。定義がなければ、名前のない文（`＊`）が使われます。`＊OnTalk` を定義すると、Reference0 に `0`（ランダム）か `1`（予約トーク）、Reference1 に予約トークの名前が入ります。
