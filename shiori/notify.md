# NOTIFY の保存

ベースウェアからの `NOTIFY` のうち、里々が内容を記録するものです。

| ID | 記録される内容 | 使い道 |
|----|----------------|--------|
| `hwnd` | キャラクターのウィンドウハンドル | `（ウィンドウハンドルN）` `get_property` の送信先 |
| `otherghostname` | 隣で起動しているゴーストの名前 | `（隣で起動しているゴースト）` `→`（話しかけ） |
| `capability` | ベースウェアの対応機能 | `response.errorlevel` に対応しているとき、エラーを応答ヘッダで通知 |

[＄NOTIFYの自動保存](../system/vars-misc.md#notifyの自動保存)が `有効` のときは、さらに次のものも記録されます。

| ID | 記録される内容 | 確認する名前 |
|----|----------------|--------------|
| `installedghostname` | 導入済みのゴースト名 | `導入済みゴースト「名前」の存在` |
| `installedshellname` | 導入済みのシェル名 | `導入済みシェル「名前」の存在` |
| `installedballoonname` | 導入済みのバルーン名 | `導入済みバルーン「名前」の存在` |
| `installedheadlinename` | 導入済みのヘッドラインセンサ名 | `導入済みヘッドライセンサ「名前」の存在` |
| `OnNotifyFontInfo` | 導入済みのフォント名 | `導入済みフォント「名前」の存在` |
| `installedplugin` | 導入済みのプラグイン | `導入済みプラグイン「名前」の存在` `…のID` |
| `rateofusegraph` | 使ってるぞグラフ | `使ってるぞグラフ「ゴースト名」の…` |

確認に使う名前は、[状態・存在確認](../system/names-state.md)にあります。

`NOTIFY` の内容も、Reference の値として `（Ｒ０）` などで参照できます。
