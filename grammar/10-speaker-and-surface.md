# スコープとサーフェス

## 喋るキャラクター（スコープ）

トークは最初、相方側（`\1`）が喋る状態で始まります。喋るキャラクターは次の方法で切り替えます。

| 書き方 | 動作 |
|--------|------|
| `：` | 本体側（0）と相方側（1）を交互に切り替える |
| `名前：` | `characters.ini` に登録した名前のキャラクターに切り替える |
| `\0` `\h` | 本体側に切り替える |
| `\1` `\u` | 相方側に切り替える |
| `\p[n]` | n 番目のキャラクターに切り替える |

すでに誰かが喋ったあとで別のキャラクターに切り替えると、切り替えの前に文字列が挿入されます。

- `：` や `名前：` で切り替えたとき: [＄スコープ切り換え時](../system/vars-script.md)（既定は `\n[half]`）
- `\0` `\1` `\p[n]` で切り替えたとき: ＄さくらスクリプトによるスコープ切り換え時（既定は空）

また、切り替えの前には、たまっている自動ウェイトがまとめて出力されます（[自動挿入](11-auto-insert.md)）。

ジャンプしたとき、`（名前）` で文を呼び出したときの、キャラクターの引き継ぎは[制御構造](08-flow-control.md#ジャンプ)を参照してください。

## サーフェスの切り替え

`（数字）` は、いま喋っているキャラクターのサーフェスを切り替える `\s[番号]` になります。

```
：（0）こんにちは。（5）はい。
```

- 切り替える番号には、そのキャラクターの[サーフェス加算値](../system/vars-surface.md#サーフェス加算値n)が足されます（`characters.ini` の `base-surface` で設定）。
- `（-1）` は、サーフェスを消す指示で、加算値は足されません。
- 半角・全角のどちらの数字でも書けます。
- さくらスクリプトの `\s[n]` を直接書いた場合は、加算値は足されません。

## 会話時サーフェス戻し

トークの応答の先頭に、キャラクターのサーフェスを既定の番号に戻す `\N\s[番号]` を付けます（相方側の既定は `10`）。

- 喋る前にサーフェスを切り替えたキャラクター（`（数字）` を最初に書いたキャラクター）は、戻しません（通常の設定のとき）。
- 設定は [＄会話時サーフェス戻し](../system/vars-surface.md#会話時サーフェス戻し)で切り替えます。
- 既定のサーフェスは [＄デフォルトサーフェスN](../system/vars-surface.md#デフォルトサーフェスn) で変えられます。
- 起動時（`OnBoot` `OnGhostChanged`）や、ウィンドウ状態の復帰（`OnWindowStateRestore` `OnShellChanged` `OnSurfaceRestore`）に対応する文が辞書になければ、サーフェスの戻しだけが返されます。
