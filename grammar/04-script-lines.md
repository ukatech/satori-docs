# 文の行の書き方

文（`＊`）の本文の各行は、行頭の文字で種類が決まります。

| 行頭 | 種類 | 詳細 |
|------|------|------|
| `＄` | 変数の代入 | [変数](06-variables.md) |
| `＞` `≫` `≧` | ジャンプ | [制御構造](08-flow-control.md) |
| `＿` | 選択肢 | [選択肢](09-choices.md) |
| `→`（文の1行目のみ） | 話しかけ | [コミュニケート](../shiori/communicate.md) |
| それ以外 | 通常の行（喋る内容） | このページ |

## 通常の行

行の中の文字は、左から順に処理されます。

| 書かれたもの | 処理 |
|--------------|------|
| `（…）` | 展開して、結果に置き換える（[（）の展開](05-kakko.md)） |
| `：` | 喋るキャラクターの切り替え（0 と 1 を交互に切り替える） |
| `\` で始まるもの | さくらスクリプト。そのまま出力される（[さくらスクリプトの扱い](13-sakura-script.md)） |
| `%` で始まるもの | ベースウェアが展開する置換タグ（`%month` など）。そのまま出力される |
| その他 | 喋る文字。そのまま出力される |

行の終わりで、[＄自動改行挿入](../system/vars-auto.md#自動改行挿入)が有効なら `\n` が付きます。

## 喋るキャラクター

トークは、最初は**相方側（`\1`）**が喋る状態で始まります。

- `：` を書くたびに、本体側（`\0`）と相方側（`\1`）が交互に入れ替わります。最初の `：` で本体側になります。
- `characters.ini` に名前を登録すると、`さくら：` のように名前で切り替えられます（[replace](03-preprocess.md#replacetxt読み込み時の置換)）。
- `\0` `\1` `\h` `\u` `\p[n]` も使えます。
- キャラクターが 3 人以上のときは `\p[n]` か、`characters.ini` の名前を使います。

```
＊OnBoot
：こんにちは。
：こんにちは、さくらさん。
```

## サーフェスの切り替え

`（数字）` で、喋っているキャラクターのサーフェスを切り替えます（`（0）` `（10）` `（-1）`）。詳しくは[スコープとサーフェス](10-speaker-and-surface.md)。

## 行の連結

物理的な行を連結したいときは、行末に `φ` を書くか、`（）` の中で改行します（[前処理](03-preprocess.md)）。
