# sync

**Category:** 変数・呼び出し

## 書式

```
（sync,呼び出し名,引数,…）
```

## 戻り値

`\![raise,OnDirectSaoriCall,呼び出し名,引数,…]` というさくらスクリプト。引数がないときは、`sync` という名前を呼び出したことにならず、`（sync）` がそのまま残ります。

## 解説

`（）` の展開はスクリプトを組み立てる時点で行われますが、`sync` を使うと、その呼び出しを「スクリプトが再生されて `\![raise]` に達した時点」まで遅らせられます。時間のかかる SAORI の呼び出しなど、再生の順序に合わせて実行したい処理に使います。

`OnDirectSaoriCall` イベントを受けた里々は、参照値をすべて `,` でつないだ文字列を `（）` の中身として呼び出します。このイベントが実行できるのは `SecurityLevel` が `local` のときだけで、応答は返しません（204 No Content）。

## 使用例

```
再生の途中で\w9（sync,set,好感度,10）好感度を変更しました。
```
