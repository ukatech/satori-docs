# 追加単語の全削除

**Category:** 単語・文字

## 書式

```
（追加単語の全削除,単語群名）
```

## 引数

| 引数 | 説明 |
|------|------|
| 単語群名 | 対象の単語群の名前 |

## 戻り値

常に空文字列。

## 解説

[単語の追加](add-word.md) で追加した単語を、その単語群についてすべて削除します。辞書に書かれた単語は残ります。

## 使用例

```
（追加単語の全削除,好きな食べ物）
```
