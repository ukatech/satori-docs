# 合成単語群

**Category:** 単語・文字

## 書式

```
（合成単語群、単語群名1、単語群名2、…）
```

## 引数

| 引数 | 説明 |
|------|------|
| 単語群名 | 対象にする単語群の名前（いくつでも） |

## 戻り値

指定した単語群の、採用条件を満たす単語すべてから、等しい確率で選んだ 1 つ。候補がなければ空文字列。引数がないときは `error: '合成単語群' : 引数が不正です。` をログに出して空文字列。

## 解説

複数の `＠` をまとめて 1 つの候補群として選びます。重複回避は働きません。選んだ単語の中の `（）` は、通常の呼び出しと同様に展開されます。外部からのイベントでも実行できます。

## 使用例

```
＠果物
りんご
みかん

＠野菜
にんじん

＊OnBoot
今日は（合成単語群、果物、野菜）が食べたいです。
```
