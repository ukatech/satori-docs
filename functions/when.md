# when

**Category:** 特殊形式

## 書式

```
（when、式、真のとき、偽のとき）
（when、式、真のとき）
```

## 引数

| 引数 | 説明 |
|------|------|
| 式 | 計算する式（[式](../grammar/07-expressions.md)） |
| 真のとき | 式の結果が 0 以外のときに展開する文字列 |
| 偽のとき | 式の結果が 0 のときに展開する文字列（省略可） |

## 戻り値

選ばれた側を展開した結果。偽で「偽のとき」がなければ空文字列。引数が 2〜3 個でないときは `引数の個数が正しくありません。`、式が計算できないときは `' 式が計算不能です。`。

## 解説

特殊形式なので、選ばれなかった側の `（）` は実行されません。ssu の [if](../ssu/if.md) は両方の枝を先に展開する点が異なります。

式の中の `（）` は数値計算用に展開され、未定義の名前や空の結果は `０` として扱われます。

## 使用例

```
（when、（好感度）>=50、仲良し、ふつう）
（when、1、（set、Y、1）、（set、Y、2））   ← Y は 1 になる
```
