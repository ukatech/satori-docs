# while

**Category:** 特殊形式

## 書式

```
（while、条件、本体）
（while、条件、開始値、本体）
```

## 引数

| 引数 | 説明 |
|------|------|
| 条件 | 毎回、本体の前に計算する式。0 になったら終了 |
| 開始値 | カウンタの初期値（省略時 0） |
| 本体 | 毎回展開する文字列 |

## 戻り値

本体の展開結果をつなげたもの。

## 解説

カウンタは `（C0）` で参照でき、1 回ごとに 1 増えます。条件の式の中でも `（C0）` を使えます。

!!! warning "無限ループ"
    繰り返しの回数そのものの上限はありません。条件が必ず偽になるようにしてください。
    1 周ごとに [＄呼び出し総数制限](../system/vars-limits.md#呼び出し総数制限)（既定 100000）を数え、超えたらそこで打ち切ります（Mc201-8以降。それ以前は、条件がいつまでも真だと里々が応答を返せなくなりました）。
    繰り返しの結果が [＄括弧展開サイズ制限](../system/vars-limits.md#括弧展開サイズ制限)を超えたときは、そこで打ち切ります（Mc201-7以降）。

## 使用例

```
（while、（C0）<3、（C0））   → 012
```
