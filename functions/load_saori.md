# load_saori

**Category:** 本体との連携

## 書式

```
（load_saori,呼び出し名,相対パス,定義済み引数,…）
```

## 引数

| 引数 | 説明 |
|------|------|
| 呼び出し名 | `（）` の中で使う名前 |
| 相対パス | SAORI の DLL のゴーストのフォルダからの相対パス |
| 定義済み引数 | 呼び出しのたびに先頭に付ける引数（省略可） |

## 戻り値

空文字列。

## 解説

`satori_conf.txt` の `＠SAORI` に書く 1 行（`呼び出し名,相対パス,…`）と同じ形式の指定で、実行中に SAORI を登録します。登録できなかった場合はエラーログに出ます。同じ呼び出し名がすでに登録されている場合も失敗します。

## 使用例

```
（load_saori,time,saori\time_check.dll）
```
