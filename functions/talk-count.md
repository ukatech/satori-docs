# 文の数

**Category:** 単語・文字

## 書式

```
（文の数、文の名前）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文の名前 | 数を調べる文（`＊名前`）の名前 |

## 戻り値

その名前で定義されている文の数（半角の数字）。文がなければ `0`。引数が 1 個でないときは `error: '文の数' : 引数が不正です。` をログに出して空文字列。

## 解説

[（文「名前」の数）](../system/names-state.md#文単語群変数)と同じ値を、関数の形で返します。名前を変数や `（）` の結果から組み立てたいときに使えます。

引数は通常の内蔵関数と同じく、先に `（）` を展開してから渡されます。先頭が数字の引数は、[＄SAORI引数の計算](../system/vars-misc.md#saori引数の計算)に従って計算されます。

外部からのイベントでも実行できます。

Mc201-4以降。それより前は名前だけが登録されていて、何を指定しても空文字列を返していました。

## 使用例

```
＊挨拶
おはよう。
＊挨拶
こんにちは。

＊OnBoot
挨拶は（文の数、挨拶）通りあります。
```

`挨拶は2通りあります。` になります。
