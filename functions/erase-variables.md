# 変数の一括削除

**Category:** 変数・呼び出し

## 書式

```
（変数の一括削除、接頭辞）
```

## 引数

| 引数 | 説明 |
|------|------|
| 接頭辞 | 消す変数の名前の先頭部分 |

## 戻り値

消した変数の個数（半角の数字）。接頭辞が空のときは何もせず `0`。

## 解説

名前が「接頭辞」で始まる変数を、すべて削除します。1 つずつ `＄名前`（値を空にした代入）を書いたのと同じ動作で、システム変数に当たる名前はその設定の解除として働きます。

- 接頭辞が空のときは、全部を消してしまう事故を防ぐため、何も消しません。
- 対象は `＄` や [set](set.md) で作った変数です。`（S0）` `（A0）` `（R0）` などの引数・結果の値は変数ではないので消えません。
- 削除した変数ごとに、ログに `＄名前／cleared.` が出ます。

**ローカルのみ**の関数です。外部からのイベントでは実行されず、空文字列になります。

Mc201-5以降。

## 使用例

一時的な変数の名前を `__` で始めておき、まとめて消す例です。

```
＊ゲーム終了
（nop、（変数の一括削除、__））
```

戻り値を捨てたいときは [nop](nop.md) で囲みます。

```
（set、__a、1）（set、__b、2）（set、_c、3）
（変数の一括削除、__）（変数の列挙、__）[（変数「_c」の存在）]
```

2 行目は `2[1]` になります（`__a` `__b` が消え、`_c` は残る）。
