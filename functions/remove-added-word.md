# 追加単語の削除

**Category:** 単語・文字

## 書式

```
（追加単語の削除、単語群名、単語）
```

## 引数

| 引数 | 説明 |
|------|------|
| 単語群名 | 対象の単語群の名前 |
| 単語 | 削除する単語 |

## 戻り値

常に空文字列。

## 解説

[単語の追加](add-word.md) で追加した単語を 1 つ削除します。辞書に書かれた単語は削除できません。削除した結果、単語群が空になった場合は、その単語群自体がなくなります。

## 使用例

```
（追加単語の削除、好きな食べ物、ラーメン）
```
