# get_property

**Category:** 本体との連携

## 書式

```
（get_property、プロパティ名）
（get_property、プロパティ名、既定値）
```

## 引数

| 引数 | 説明 |
|------|------|
| プロパティ名 | 取得するプロパティの名前 |
| 既定値 | 取得できなかったときの結果（省略時は空文字列） |

## 戻り値

プロパティの値。取得できなかったときは既定値。

## 解説

ベースウェア（SSP など）に SSTP の `EXECUTE` で `GetProperty` コマンドを送り、プロパティの値を取得します。送り先は、`NOTIFY hwnd` などで得たゴーストのメインウィンドウです。ウィンドウがまだ分からないとき（起動直後など）や、ベースウェアが対応していないときは、既定値になります。プロパティ名の仕様はベースウェアのドキュメントを参照してください。

## 使用例

```
現在のゴーストは（get_property、currentghost.name、不明）です。
```
