# vncall

**Category:** 変数・呼び出し

## 書式

```
（vncall、呼び出し先、名前1、名前2、…）
```

## 引数

| 引数 | 説明 |
|------|------|
| 呼び出し先 | 呼び出す単語群・文・変数の名前 |
| 名前 | 呼び出し先に渡す引数の**名前**。それぞれを `（名前）` として展開した結果が引数になる |

## 戻り値

呼び出し先の展開結果。

## 解説

[call](call.md) との違いは、引数を「値」ではなく「名前」で渡し、名前の展開結果を呼び出し先の `（A0）` `（A1）`… にすることです。単語群や変数を渡して、呼び出しのたびに選ばれた結果を渡したいときに使います。

見つからない名前の引数は空文字列になります。呼び出し先が見つからないときは空文字列を返します。

Mc201-4: 呼び出し先が見つからないとき、最後の引数の展開結果を返していた不具合を直しました。

## 使用例

```
＠色
赤
青

＊紹介
好きな色は（A0）です。

＊OnBoot
（vncall、紹介、色）
```
