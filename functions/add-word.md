# 単語の追加

**Category:** 単語・文字

## 書式

```
（単語の追加,単語群名,単語）
```

## 引数

| 引数 | 説明 |
|------|------|
| 単語群名 | 追加先の単語群の名前（なければ作られる） |
| 単語 | 追加する単語 |

## 戻り値

常に空文字列。

## 解説

実行中に単語群へ単語を追加します。同じ単語がすでにある場合は追加しません。追加した単語はセーブデータ（`satori_savedata.txt`）に `＠単語群名` として保存され、次回起動時にも残ります。

辞書に書いた単語は、この関数で削除できません。[追加単語の削除](remove-added-word.md) の対象は、この関数で追加した単語だけです。

## 使用例

```
（単語の追加,好きな食べ物,ラーメン）
```
