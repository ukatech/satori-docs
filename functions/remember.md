# remember

**Category:** 変数・呼び出し

## 書式

```
（remember、n）
```

## 引数

| 引数 | 説明 |
|------|------|
| n | 何回前の応答か（0 が直前） |

## 戻り値

過去にゴーストが返したスクリプト。範囲外のときや引数が 1 個でないときは空文字列。

## 解説

里々が返した `On` で始まるイベントの応答スクリプトを、最大 64 件まで覚えています。`remember` はそのうち n 回前のものを取り出します。直前の話をもう一度言わせたいときなどに使います。

覚えているのは、実際に返した最終形のスクリプトです（`\e` などのタグを含みます）。デバッグ用の ShioriEcho の応答は覚えません。

## 使用例

```
＊OnMouseDoubleClick
もう一度言いますね。（remember、0）
```
