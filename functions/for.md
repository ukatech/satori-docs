# for

**Category:** 特殊形式

## 書式

```
（for、開始、終了、本体）
（for、開始、終了、増分、本体）
```

## 引数

| 引数 | 説明 |
|------|------|
| 開始 | カウンタの初期値 |
| 終了 | カウンタの終了値（この値も含む） |
| 増分 | 1 回ごとの変化量（省略時 1）。向きは開始と終了の大小で決まり、符号は無視される |
| 本体 | 毎回展開する文字列 |

## 戻り値

本体の展開結果をつなげたもの。増分が 0 のときは `forの増分に0が指定されました。`。

## 解説

カウンタを `（C0）` で参照します。開始が終了以下なら増やしながら、大きければ減らしながら繰り返します。

## 使用例

```
（for、1、3、（C0））          → 123
（for、3、1、（C0））          → 321
（for、0、10、5、（C0））       → 0510
（for、1、2、（for、5、6、（C0）（C1））/）   → 5161/5262/
```
