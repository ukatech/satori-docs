# 変数の一括コピー

**Category:** 変数・呼び出し

## 書式

```
（変数の一括コピー、元の接頭辞、先の接頭辞）
```

## 引数

| 引数 | 説明 |
|------|------|
| 元の接頭辞 | コピーする変数の名前の先頭部分 |
| 先の接頭辞 | コピー先の名前の先頭部分。空にすると接頭辞を取り除いた名前になる |

## 戻り値

コピーした変数の個数（半角の数字）。元の接頭辞が空のとき、または元と先が同じときは何もせず `0`。

## 解説

名前が「元の接頭辞」で始まる変数を、先頭を「先の接頭辞」に付け替えた名前へ代入します。`slot1.名前` を `slot2.名前` に写す、`slot1.名前` を `名前` に戻す、といった使い方ができます。

- 代入は `＄名前＝値` と同じように行われます（値の計算はしません）。コピー先の名前がシステム変数に当たる場合は、その設定として働きます。
- コピー先にある変数は上書きされますが、コピー元にない変数は消えません。コピー先を空にしてから写したいときは、先に [変数の一括削除](erase-variables.md) を使います。
- コピーする変数を先に全部集めてから代入するので、先の接頭辞が元の接頭辞で始まる場合（`slot1.` → `slot1.x`）でも、写した変数がもう一度写されることはありません。
- 値が空の変数を写すと、コピー先の変数は削除されます（`＄名前` に空を代入したのと同じ）。
- コピー先の名前が数字だけになるものは代入されません。

**ローカルのみ**の関数です。外部からのイベントでは実行されず、空文字列になります。

Mc201-5以降。

## 使用例

```
（set、__a、1）（set、__b、2）
（変数の一括コピー、__、slot1.）（変数の列挙、slot1.）
（変数の一括コピー、slot1.、）（a）（b）
```

2 行目は `2slot1.a,slot1.b`、3 行目は `212` になります。

セーブスロットの例です。

```
＊セーブ
（nop、（変数の一括削除、slot（R0）.））（nop、（変数の一括コピー、__、slot（R0）.））

＊ロード
（nop、（変数の一括削除、__））（nop、（変数の一括コピー、slot（R0）.、__））
```
