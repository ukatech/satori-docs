# set

**Category:** 変数・呼び出し

## 書式

```
（set、変数名、値）
```

## 引数

| 引数 | 説明 |
|------|------|
| 変数名 | 代入する変数の名前（システム変数も指定できる） |
| 値 | 代入する値。空にするとその変数を削除する |

## 戻り値

通常は空文字列。

## 解説

`＄変数名＝値` の代わりに `（）` の中から変数を代入します。`＄` の行と違い、次の点が異なります。

- 値の計算はしません。`＄A＝1+1` は `２`（全角）になりますが、`（set、A、1+1）` は `1+1` です。ただし、数字で始まる引数は里々が先に計算してから渡すことがあるため（[ssu の引数の計算](../ssu/index.md#引数の計算)）、`1+1` と書くと結果として `2`（半角）が代入されます。
- 値は書いたとおりに（半角のまま）代入されます。`＄` の行では、数字だけの値は全角の数字にそろえられます。
- 値が空なら、その変数を削除します。システム変数の場合はその設定の解除として働きます。
- 変数名が数字だけの場合は代入できません。

システム変数（`喋り間隔` など）も指定できます。

## 使用例

```
（set、好感度、10）
（set、名前、（ユーザー名））
（set、喋り間隔、60）
```
