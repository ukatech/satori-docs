# call

**Category:** 変数・呼び出し

## 書式

```
（call,名前,引数0,引数1,…）
```

## 引数

| 引数 | 説明 |
|------|------|
| 名前 | 呼び出す単語群・文・変数の名前 |
| 引数 | 呼び出し先に渡す引数。`（A0）` `（A1）`… で参照する |

## 戻り値

呼び出し先の展開結果。

## 解説

引数付きで、単語群・文・変数を呼び出します。呼び出し先では次の名前で引数を参照できます。

| 名前 | 内容 |
|------|------|
| `（A0）` `（A1）`… | 渡された引数（全角の `Ａ０` も可） |
| `（Aの数）` | 渡された引数の個数 |

引数は呼び出しごとに独立しています。呼び出し先がさらに `call` を使っても、呼び出し元の `（A0）` は変わりません。範囲外の引数は空文字列になります。

引数は、呼び出す前に展開されています。

## 使用例

```
＊あいさつ
（A0）さん、こんにちは。（Aの数）個の引数を受け取りました。

＊OnBoot
（call,あいさつ,太郎,花子）
```
