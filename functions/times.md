# times

**Category:** 特殊形式

## 書式

```
（times、回数、本体）
（times、回数、開始値、本体）
```

## 引数

| 引数 | 説明 |
|------|------|
| 回数 | 繰り返す回数 |
| 開始値 | カウンタの初期値（省略時 0） |
| 本体 | 毎回展開する文字列 |

## 戻り値

本体の展開結果をつなげたもの。引数の個数が合わないときは `引数の個数が正しくありません。`。

## 解説

カウンタは `（C0）` で参照します。開始値から 1 ずつ増え、回数だけ繰り返します（開始値が 5、回数が 3 なら 5, 6, 7）。入れ子にしたときは、内側のカウンタが `（C0）`、その外側が `（C1）` です。

繰り返しの結果が [＄括弧展開サイズ制限](../system/vars-limits.md#括弧展開サイズ制限)を超えたときは、そこで打ち切ります（Mc201-7以降）。

## 使用例

```
（times、3、（C0））        → 012
（times、3、5、（C0））      → 567
```
