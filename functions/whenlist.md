# whenlist

**Category:** 特殊形式

## 書式

```
（whenlist、値、条件1、結果1、条件2、結果2、…、それ以外）
```

## 引数

| 引数 | 説明 |
|------|------|
| 値 | 比較される値 |
| 条件 | 比較演算子と右辺（`<10` など） |
| 結果 | 条件が真のときに展開する文字列 |
| それ以外 | 末尾に置くと、どれも真でなかったときに展開する文字列 |

## 戻り値

最初に真になった条件の結果。どれも真でなく「それ以外」もなければ空文字列。引数が 2 個未満のときは `引数の個数が正しくありません。`。

## 解説

ssu の [iflist](../ssu/iflist.md) と同じ判定を、特殊形式で行います。「値」を展開し、各「条件」を展開して連結した式を順に計算します。選ばれなかった結果の `（）` は実行されません。

## 使用例

```
（whenlist、（好感度）、<30、冷たい、<70、ふつう、親しい）
```
