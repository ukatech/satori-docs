# 変数の列挙

**Category:** 変数・呼び出し

## 書式

```
（変数の列挙、接頭辞）
（変数の列挙、接頭辞、区切り）
```

## 引数

| 引数 | 説明 |
|------|------|
| 接頭辞 | 探す変数の名前の先頭部分。空ならすべての変数 |
| 区切り | 名前の間に入れる文字列（省略時は半角の `,`） |

## 戻り値

名前が「接頭辞」で始まる変数の名前を、区切りでつないだもの。該当する変数がなければ空文字列。

## 解説

- 名前は文字コードの順（Unicode のコードポイント順）に並びます。
- 対象は `＄` や [set](set.md) で作った変数です。システム変数も、`＄` で設定したものは変数として残っているので含まれます。`（S0）` `（A0）` などは含まれません。
- 結果を別の関数の引数に入れるときは、区切りが引数の区切りと同じにならないように注意してください。里々は内側の `（）` を先に展開してから引数に分けるため、`,` でつないだ結果を `（…、（変数の列挙、__））` のように渡すと、名前ごとに別の引数になります。そのようなときは `|` など、引数の区切りに使っていない文字を指定します。

外部からのイベントでも実行できます。

Mc201-5以降。接頭辞を空にしてすべての変数を列挙できるのは Mc203-1以降（それより前は空文字列が返っていました）。

## 使用例

```
（set、__a、1）（set、__b、2）（set、_c、3）
（変数の列挙、__）
（変数の列挙、__、|）
```

2 行目は `__a,__b`、3 行目は `__a|__b` になります。

[split_to](split_to.md) と組み合わせると、1 つずつ取り出せます。

```
（split_to、名前、（変数の列挙、__、|）、|）
（名前の数）個、最初は（名前0）
```

2 行目は `2個、最初は__a` になります。
