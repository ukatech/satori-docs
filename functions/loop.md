# loop

**Category:** 変数・呼び出し

## 書式

```
（loop、名前、最大）
（loop、名前、初期値、最大）
（loop、名前、初期値、最大、増分）
```

## 引数

| 引数 | 説明 |
|------|------|
| 名前 | 繰り返し呼び出す単語群・文・変数の名前 |
| 初期値 | カウンタの初期値（省略時 1） |
| 最大 | カウンタの終了値（この値も含む） |
| 増分 | カウンタの増分（省略時 1）。負数なら減らしていく |

## 戻り値

毎回の展開結果をつなげたもの。呼び出し先が見つからなかったときや、増分が 0 のときは空文字列。

## 解説

カウンタを変えながら、指定した名前を繰り返し呼び出します。カウンタは変数「名前カウンタ」に入り、呼び出し先で `（名前カウンタ）` として参照できます。ループが終わるとこの変数は削除されます。

カウンタは**半角の数字**です（`1`）。`＄名前＝式` の結果は全角（`１`）なので、カウンタで変数名を組み立てると別の変数になります（`（項目（行カウンタ））` は `項目1` で、`＄項目１＝…` で作った変数とは別物）。全角にそろえるときは `（han2zen、（行カウンタ））` をはさみます。

- 増分が正のとき、初期値が最大より大きければ何も実行しません。
- 増分が負のとき、初期値が最大より小さければ何も実行しません。
- 結果が [＄括弧展開サイズ制限](../system/vars-limits.md#括弧展開サイズ制限)を超えたときは、そこで繰り返しを打ち切ります。最大が `2147483647` のときも、カウンタがあふれずに終わります（どちらも Mc201-7以降）。

繰り返しの本体を `（）` の中に書きたいときは、特殊形式の [times](times.md) [for](for.md) [while](while.md) を使います。

## 使用例

```
＊行
（行カウンタ）行目。

＊OnBoot
（loop、行、3）
（loop、行、2、4）
（loop、行、5、1、-2）
```
