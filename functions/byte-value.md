# バイト値

**Category:** 単語・文字

## 書式

```
（バイト値,n）
```

## 引数

| 引数 | 説明 |
|------|------|
| n | Unicode のコードポイント（10 進数。全角数字も可） |

## 戻り値

そのコードポイントの 1 文字。サロゲート領域（0xD800〜0xDFFF）の値のときは空文字列。引数がないときは `error: 'バイト値' : 引数が不正です。` をログに出して空文字列。

## 解説

`,` や `（` のように、書くと里々の記法として解釈されてしまう文字を作るときに使えます。0x10000 以上の値は、サロゲートペアの 1 文字になります。

!!! note "旧版との違い"
    ACP 版（master）では「1 バイトの文字」を返しましたが、Unicode 版では n を Unicode のコードポイントとして 1 文字を返します。0〜127 の範囲は同じ結果です。

外部からのイベントでも実行できます。

## 使用例

```
（バイト値,65）      → A
（バイト値,12354）   → あ
（バイト値,128512）  → 😀
```
