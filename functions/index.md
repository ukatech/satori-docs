# （）内蔵関数

里々の `（）` の中で、名前と引数を `,` などで区切って呼び出せる内蔵の関数です。SAORI のように呼び出せますが、里々本体に組み込まれています。

```
（set、好感度、10）
（loop、自己紹介、3）
（when、（好感度）>=50、仲良し、ふつう）
```

同梱 SAORI の [ssu](../ssu/index.md) の関数（`calc` `if` など）とは別のものです。

## 呼び出し方の種類

| 種類 | 引数の扱い |
|------|------------|
| 通常の内蔵関数 | 引数の中の `（）` を**先に展開してから**引数に分ける（`set` `loop` `call` など） |
| 特殊形式 | 引数を分けてから、**必要な引数だけ**を展開する（`when` `whenlist` `times` `while` `for`） |

特殊形式は、使わない枝の `（）` を実行しません。これは ssu の [if](../ssu/if.md) との違いです（`if` は真偽どちらの枝の `（）` も先に展開されます）。

## 実行できる条件（ローカルのみ）

`SecurityLevel` が `local` でないリクエスト（外部からのイベントなど）では、次の関数は実行されず、空文字列になります（ログに `local/Localでないので蹴りました` と出ます）。

`set` `loop` `sync` `remember` `call` `vncall` `equal` `get_property` `set_property` `load_saori` `単語の追加` `追加単語の削除` `追加単語の全削除`

`nop` `バイト値` `合成単語群` と特殊形式は、外部からのイベントでも実行できます。外部イベントを許可する方法は[プロトコルとリクエスト処理](../shiori/protocol.md#外部からのイベントの許可)を参照してください。
