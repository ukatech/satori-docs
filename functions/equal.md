# equal

**Category:** 変数・呼び出し

## 書式

```
（equal、文字列1、文字列2）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文字列1 | 比較する文字列 |
| 文字列2 | 比較する文字列 |

## 戻り値

まったく同じなら `1`、違えば `0`。引数が 2 個でないときは空文字列。

## 解説

2 つの文字列を、大文字小文字・全角半角を区別して完全に比較します。区別しない比較は ssu の [compare](../ssu/compare.md) を使います。

## 使用例

```
（equal、a、a）   → 1
（equal、a、b）   → 0
（equal、１、1）  → 0
```
