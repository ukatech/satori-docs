# 状態・存在確認

名前に含まれる `「」` の中は、確認したい名前を書きます。多くは `1`（ある）か `0`（ない）を返します。数値は全角の場合と半角の場合があります。

## 文・単語群・変数

| 名前 | 値 |
|------|----|
| `（文「名前」の存在）` | 文 `＊名前` があれば `1` |
| `（文「名前」の数）` | その名前の文の定義数 |
| `（単語群「名前」の存在）` | 単語群 `＠名前` があれば `1` |
| `（単語群「名前」の数）` | 単語群の単語の数（全角） |
| `（単語群「名前」の重複回避枯渇）` | 重複回避で全部使い切っていれば `1` |
| `（変数「名前」の存在）` | 変数があれば `1` |
| `（変数「名前」か０）` | 変数の値。なければ `０` |
| `（変数「名前」か空文字列）` | 変数の値。なければ空文字列 |

`（文「名前」の他）` のように、表にない書き方は見つからない名前として扱われます（Mc201-4以降。それより前は空文字列でした）。

## 辞書の統計

`（count名前）` で、辞書の統計を全角の数字で返します。

| 名前 | 値 |
|------|----|
| `countWords` | 単語群の数 |
| `countWord` | 単語の総数 |
| `countTalk` | 文の総数 |
| `countNoNameTalk` | 名前のない文（ランダムトーク）の数 |
| `countEventTalk` | `On` で始まる文の数 |
| `countOtherTalk` | それ以外の名前のある文の数 |
| `countVariable` | 変数の数 |
| `countAnchor` | アンカーの数 |
| `countLine` | 文と単語の総行数 |
| `countParenthesis` | 辞書中の `（` の数 |

表にない名前（`countXyz` など）は見つからない名前として扱われます（Mc201-4以降。それより前は空文字列でした）。

## トーク予約

| 名前 | 値 |
|------|----|
| `次のトーク` | 次に予約されているトーク名 |
| `次からN回目のトーク` | N 回後に予約されているトーク名 |
| `トーク「名前」の予約有無` | 予約されていれば `1` |
| `予約トーク数` | 予約されている件数（全角） |

## 導入済みリソース

[＄NOTIFYの自動保存](vars-misc.md#notifyの自動保存)が `有効` のときに、ベースウェアから通知された内容を確認できます。

| 名前 | 値 |
|------|----|
| `導入済みゴースト「名前」の存在` | あれば `1` |
| `導入済みシェル「名前」の存在` | 同上 |
| `導入済みバルーン「名前」の存在` | 同上 |
| `導入済みヘッドライセンサ「名前」の存在` | 同上 |
| `導入済みフォント「名前」の存在` | 同上 |
| `導入済みプラグイン「名前」の存在` | 同上 |
| `導入済みプラグイン「名前」のID` | プラグインの ID |
| `使ってるぞグラフ「ゴースト名」の本体側の名前` | 使ってるぞグラフの情報 |
| `使ってるぞグラフ「ゴースト名」の相方側の名前` | 同上 |
| `使ってるぞグラフ「ゴースト名」の起動回数` | 同上 |
| `使ってるぞグラフ「ゴースト名」の単純累計分` | 同上 |
| `使ってるぞグラフ「ゴースト名」の起動割合` | 同上 |
| `使ってるぞグラフ「ゴースト名」の状態` | 同上 |

## 起動中のゴースト・ウィンドウ・プロセス

| 名前 | 値 |
|------|----|
| `起動しているゴースト数` | 自分を含む数（全角） |
| `隣で起動しているゴースト` | 隣にいる別のゴーストの名前（1 つ） |
| `起動中ゴースト「名前」の存在` | 隣のゴーストに含まれれば `1` |
| `ゴースト名の存在` | FMO の情報から、その名前（本体側または相方側）のゴーストがあれば `1`（`名前の存在` の形で書く） |
| `ゴースト名のサーフェス` | そのゴーストの現在のサーフェス番号。なければ `-1` |
| `FMOn項目名` | FMO の n 番目のゴーストの項目（`FMO0hwnd` など）。n を省いた形（`FMOname`）は見つからない名前として扱われる（Mc201-4以降） |
| `ウィンドウハンドルN` | N 番目のキャラクターのウィンドウハンドル |
| `ウインドウ「タイトル」の存在` | ウインドウのハンドル（なければ `０`） |
| `「文字列」を含むウインドウの存在` | タイトルに含む部分一致版 |
| `プロセス「名前」の存在` | プロセス ID（なければ `０`）。名前は実行ファイル名 |
| `「文字列」を含むプロセスの存在` | 部分一致版 |

ウィンドウとプロセスの確認は、Windows 版でのみ動作します。

## サーフェス

| 名前 | 値 |
|------|----|
| `サーフェスN` | N 番目のキャラクターの現在のサーフェス番号（`OnSurfaceChange` で更新） |
| `前回終了時サーフェスN` | 前回のトークの終了時点のサーフェス番号 |

## リクエストと環境

| 名前 | 値 |
|------|----|
| `イベント名` | 現在のリクエストの ID |
| `直前の選択肢名` | 最後に選ばれた選択肢の ID（`選択ＩＤ` と同じ値）。選択肢が選ばれる前は空。Mc201-1 までは常に空で、Mc201-2 で記録されるようになった |
| `ヘッダ名` | リクエストのヘッダの値（`Sender` `Status` `Reference0` など。ほかの名前より後に判定される） |
| `pwd` | ゴーストのフォルダ |
| `本体の所在` | 本体（ベースウェア）の実行ファイルのあるフォルダ（Windows のみ） |
| `全変数列挙` | 全変数を `＄名前<タブ>値` の形で列挙（デバッグ有効かつローカルのみ） |

## その他

| 名前 | 値 |
|------|----|
| `里々のバージョン` | `phase Mc201-1` のようなバージョン文字列 |
| `里々のライセンス` | ライセンス文（改行は `\n`） |
| `セーブデータ読み込み` | 読み込み結果（`正常` `バックアップ` `失敗`） |
| `isempty文字列` | `isempty` の直後に 1 文字だけ続く形のとき `1` |

## SHIORI ID としての利用

`On` で始まらない名前や存在しないイベント名を、そのまま SHIORI のリクエストの ID にすると、`（ID）` を展開した結果を返します。`version` `name` `craftman` `craftmanw` のほか、これらの組み込み名や文・単語群の名前も ID として使えます。詳しくは[プロトコルとリクエスト処理](../shiori/protocol.md)。
