# 喋りとトーク予約

## ＄喋り間隔

ランダムトーク（自発的なおしゃべり）の間隔を秒で指定します。

- 既定値は `0`（ランダムトークをしない）です。
- 3 未満の値は 0（喋らない）として扱われます。
- 設定した時点で、次のトークまでの残り時間がリセットされます。

実際の間隔は、[＄喋り間隔誤差](#喋り間隔誤差)の分だけばらつきます。ランダムトークの仕組みは[ランダムトークとタイマ](../shiori/random-talk.md)を参照してください。

```
＄喋り間隔＝60
```

## ＄喋り間隔誤差

`喋り間隔` に対する誤差を、パーセントで指定します。

- 既定値は `10`。0〜100 に丸められます。
- 間隔が 60 秒で誤差が 10 なら、次の喋りまでの時間は 54〜66 秒の間でランダムになります。

## ＄見切れてても喋る

`有効` にすると、キャラクターが画面から見切れていてもランダムトークをします。既定は無効です。

## ＄今回は喋らない

`有効` にすると、その応答では何も返さず（204 No Content）、喋りません。その 1 回だけ有効で、セーブされません。

## ＄次のトーク

ランダムトークで、次に喋るトークの名前を予約します。すでに予約があるときは、その次の順番に追加されます。

```
＄次のトーク＝夜のあいさつ
```

予約は[名前の一覧](names-state.md#トーク予約)で確認できます。セーブデータに保存されます。

## ＄次からN回目のトーク

N 回後のランダムトークを予約します（N は 1 以上）。`＄次のトーク` は `＄次から1回目のトーク` と同じです。その順番が埋まっているときは、空いている次の順番になります。N が 0 以下だとエラーログが出て予約されません。

```
＄次から3回目のトーク＝おやすみ
```

## ＄トーク予約のキャンセル

値に指定したトークの予約をすべて取り消します。`＊` を指定すると、すべての予約を取り消します。

## ＄教わること

教わり（ティーチボックス）のジャンル名を設定し、同時に `\![open,teachbox]` を出力します。

```
＄教わること＝好きな食べ物
```
