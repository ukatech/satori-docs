# セーブ・辞書・タイマ・重複回避

## ＄セーブデータ暗号化

`有効` にすると、セーブデータを `satori_savedata.sat` の暗号化形式で保存します。既定は無効（`satori_savedata.txt`）。詳しくは[セーブデータ](../grammar/15-save-data.md)。

## ＄タイマ変数はセーブしない

`有効` にすると、タイマの変数（`名前タイマ`）をセーブデータに書き出しません。

## ＄自動セーブ間隔

秒単位で自動セーブを行う間隔です。0 以下だと自動セーブしません（既定）。

## ＄手動セーブ

値を `実行` にすると、その場でセーブします。

## ＄辞書リロード

値を `実行` にすると、応答を返したあとに辞書を再読み込みします（アンロードしてロードし直します）。

## ＄辞書フォルダ

辞書を探すフォルダを、ゴーストのフォルダからの相対パスで指定します。複数ある場合は `,` で区切ります。指定すると辞書を再読み込みします。指定がなければゴーストのフォルダ直下だけを探します。

## ＄辞書拡張子・＄辞書接頭辞

読み込む辞書ファイルの拡張子（既定 `txt`）と接頭辞（既定 `dic`）です。**`＊初期化`（`satori_conf.txt`）の中で設定した値**だけが読み込みに使われます。

## タイマ

### ＄名前タイマ

`＄名前タイマ＝秒数` と書くと、その秒数のあとに `＊名前` のトークを実行します。詳しくは[ランダムトークとタイマ](../shiori/random-talk.md#タイマ)。

- 秒数が 1 未満だと、そのタイマをキャンセルします。
- 残り時間は、変数 `名前タイマ` を読むと分かります。
- 秒数は `＄名前タイマ＝３*60` のように式でも書けます（Mc201-11以降。それより前は、先頭の数字だけが読まれて 3 秒になっていました）。
- `＊名前` がないときは、`＊OnSatoriTimer` が実行されます（Mc201-11以降。[OnSatoriTimer](../shiori/satori-events.md#onsatoritimer)）。

### ＄全タイマ解除

値を `実行` にすると、すべてのタイマを解除します。

## 重複回避

### ＄単語群「名前」の重複回避
### ＄文「名前」の重複回避

単語群や文で、同じものが続けて選ばれるのを避ける方法を指定します。名前に `＊` を指定するとすべての単語群（文）が対象です。値は `方法、期間` の形です。この変数は保存されません。

詳しくは[重複回避](../grammar/12-overlap-avoidance.md)を参照してください。

```
＄単語群「＊」の重複回避＝有効、トーク中
＄文「自己紹介」の重複回避＝直前
```

## ＄セーブデータ読み込み

セーブデータの読み込み結果を保持する読み取り用の名前です。[名前の一覧](names-state.md#その他)を参照してください（代入した値は保存されません）。
