# マウス反応

なでられ（`OnMouseMove`）に関する設定です。動作の全体は[デフォルトの動作](../shiori/default-behaviors.md)を参照してください。

## ＄なでられ反応回数

`なでられ` の反応を起こすまでに必要な `OnMouseMove` の回数（同じ場所での）です。既定は `60`。

## ＄なでられ持続秒数

なでている状態と見なす期間（秒）です。既定は `2`。この間に `OnMouseMove` が来ないと、それまでの回数は 0 に戻ります。

## ＄トーク中のなでられ反応

`有効` にすると、別のトーク中でもなでられに反応します。既定は無効（トーク中・誘導中・パッシブモード中・時間クリティカル中は反応しません）。

## ＄なでられ時実行イベント

`なでられ時の反応` を指定すると、なでられたときに `＊なでられ時の反応` を実行します（この文があるとき）。それ以外の値は `デフォルト` として扱われ、`＊(Reference3)(Reference4)なでられ` を実行します。
