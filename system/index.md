# システム変数・組み込み名

里々には、ゴーストの動作を変える「システム変数」と、`（）` で状態を読み取れる「組み込み名」があります。

## システム変数

`＄名前＝値` の形で代入すると、里々の動作が変わる変数です。ふつうの変数と同じように書きますが、代入した瞬間に動作へ反映されます。

```
＊初期化
＄喋り間隔＝120
＄自動改行挿入＝無効
```

- 設定は多くの場合 `＊初期化`（`satori_conf.txt`）に書きます。
- 値が真偽の項目は、`有効` と書いたときだけ真で、それ以外（`無効` を含む）は偽です。
- システム変数に代入した値は、ふつうの変数としても保存され、セーブデータに書き出されます（次回起動時に復元されます）。ただし「保存されない」と書かれたものは除きます。
- `今回は…` で始まる変数は、その 1 回の応答（1 トーク）にだけ有効で、セーブされません。
- 値を空にすると（`＄名前` のみ、または `＄名前＝`）、変数が削除されます。項目によっては設定が解除されます。

## 組み込み名

`（名前）` の形で、値や状態を読み取れる名前です。変数と違い、代入はできません。

| ページ | 内容 |
|--------|------|
| [引数・参照値の名前](names-refs.md) | `Ｒ０`（Reference）、`Ａ０`（call の引数）、`Ｓ０`（SAORI の戻り値）、`Ｈ１`（履歴）、`Ｃ０`（ループカウンタ） |
| [時刻・経過時間](names-time.md) | 現在時刻、起動時間、累計時間、`乱数` |
| [状態・存在確認](names-state.md) | 文・単語群・変数の存在、個数、導入済みリソース、ゴースト情報、トーク予約など |
