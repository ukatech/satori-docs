# スクリプトへの付加

トークの決まった場所に、さくらスクリプトなどの文字列を自動で挿入する設定です。値は全角の記号などが半角にそろえられて保存されます（`zen2han` 相当）。

| 変数 | 挿入される場所 | 既定値 |
|------|----------------|--------|
| ＄スコープ切り換え時 | `：` などで、すでに喋ったキャラクターから別のキャラクターに切り替わるとき | `\n[half]` |
| ＄さくらスクリプトによるスコープ切り換え時 | `\0` `\1` `\p[n]` で、すでに喋ったキャラクターから別のキャラクターに切り替わるとき | （空） |
| ＄トーク開始時 | トークの先頭（サーフェス戻しの前） | （空） |
| ＄トーク終了時 | トークの末尾（`\e` の前） | （空） |
| ＄選択肢開始時 | 選択肢（`＿`）の直前 | （空） |
| ＄選択肢終了時 | 選択肢の直後 | `\n` |

- `トーク開始時` と `トーク終了時` は、何かを喋ったトーク（またはランダムトーク）にだけ付きます。
- 値を空にすると、それぞれの設定が空文字列に戻ります（既定値には戻りません）。

## ＄スクリプトの一番頭

応答スクリプトの一番前に付ける文字列です。**その 1 回の応答だけ**有効で、次のリクエストでは空に戻ります。トークの中で設定して使います。

```
＊OnBoot
＄スクリプトの一番頭＝\![lock,repaint]
やあ。
```
