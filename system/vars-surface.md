# サーフェス

サーフェス切り替えに関する設定です。仕組みは[スコープとサーフェス](../grammar/10-speaker-and-surface.md)を参照してください。

## ＄会話時サーフェス戻し

トークの前に、サーフェスを既定のもの（デフォルトサーフェス）へ戻すかどうかを指定します。

| 値 | 動作 |
|----|------|
| 有効（既定） | トークの中で、喋る前にサーフェスを変更しなかったキャラクターだけ戻す |
| 強制 | 戻す対象のキャラクターすべてを戻す |
| それ以外 | 戻さない（`\1` だけを出力する） |

`＄会話時サーフィス戻し` という書き方も同じ意味です。

## ＄今回は会話時サーフェス戻し

`会話時サーフェス戻し` を、その 1 回の応答だけ変更します。値は同じです。セーブされません。（`サーフィス` の書き方も可）

## ＄サーフェス加算値N

キャラクターごとの、サーフェス番号に加える値です（N は 0 が本体側、1 が相方側、2 以降は追加のキャラクター）。

- `（0）` や `（10）` などで切り替えるサーフェス番号にこの値が足されます（`-1` は足されません）。
- 同時に、そのキャラクターのデフォルトサーフェスもこの値になります。
- `characters.ini` の `base-surface` で設定した値が、起動時にこの変数へ入ります。

```
＄サーフェス加算値0＝0
＄サーフェス加算値1＝10
```

## ＄デフォルトサーフェスN

N 番目のキャラクターの、既定のサーフェス番号です。既定値は、相方側（N=1）が `10` です。トークの途中で変更しても、次の応答から有効になります。

```
＄デフォルトサーフェス1＝11
```
