# 制限値

無限ループなどで応答が返らなくなることを防ぐための制限です。負数は 0 になり、0 は「制限しない」を意味します。

## ＄呼び出し回数制限

`（）` による呼び出しが入れ子になる深さの上限です。既定は `200`。

超えると `呼び出し回数超過` とログに出て、そこは `（名前）` の形のまま残ります。

## ＄ジャンプ回数制限

1 回の応答の中で、`＞` `≫` `≧` によるジャンプを行える回数の上限です。既定は `20000`。

超えると `ジャンプ回数超過` とログに出て、そこでトークを打ち切ります。

## ＄括弧展開サイズ制限

1 つの文字列を `（）` 展開した結果の長さ（文字数）の上限です。既定は `262144`（256×1024）。

超えると `括弧展開サイズ超過` とログに出て、その時点までの結果を使います。

!!! note "繰り返しの回数には上限がありません"
    [times](../functions/times.md) [for](../functions/for.md) [while](../functions/while.md) [loop](../functions/loop.md) の繰り返しの回数そのものには、上限がありません。ただし、繰り返しの結果の長さ（文字数）が `＄括弧展開サイズ制限` を超えると、`繰り返しの結果が大きすぎるので、打ち切りました` とログに出て、そこで繰り返しを打ち切ります（Mc201-7以降）。結果が短いままの無限ループ（`（while、1、）` など）は、従来どおり止まりません。
