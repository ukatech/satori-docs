# 引数・参照値の名前

`（）` の中で使える、文字と番号の組み合わせの名前です。英字は `R` `H` `A` `S` `C`（大文字）で、全角の `Ｒ` `Ｈ` `Ａ` `Ｓ` `Ｃ` と、全角の数字でも書けます。

| 名前 | 意味 |
|------|------|
| `（R0）` `（R1）`… | イベントの Reference0・Reference1… |
| `（Rの数）` | Reference の個数 |
| `（A0）` `（A1）`… | [call](../functions/call.md) / [vncall](../functions/vncall.md) で渡された引数 |
| `（Aの数）` | 渡された引数の個数（呼ばれていなければ 0） |
| `（S0）` `（S1）`… | 直前の SAORI（ssu を含む）の戻り値（Value0・Value1…） |
| `（Sの数）` | 戻り値の個数 |
| `（H1）` `（H2）`… | このトークですでに展開した `（）` の結果の履歴 |
| `（C0）` `（C1）`… | [times](../functions/times.md) / [for](../functions/for.md) / [while](../functions/while.md) のループカウンタ |

## Ｒ（Reference）

イベントに付いてきた Reference0・1… の値です。存在しない番号は空文字列になります。`＄Ｒ０＝値` のように代入して書き換えることもできます。

## Ａ（call の引数）

`call` / `vncall` の呼び出し先で使います。呼び出しごとに独立していて、範囲外は空文字列です。

## Ｓ（SAORI の戻り値）

SAORI が返した `Value0`… が入ります。`＄Ｓ０` のようにも書けますが、`Sの数` は代入できません。SAORI を呼ぶたびに（戻り値があるとき）内容が入れ替わります。セーブデータには保存されません。

## Ｈ（履歴）

トークの中で成功した `（）` の展開結果が、展開された順に記録されます。`（H1）` は最初の結果、`（H2）` は 2 番目の結果です。`（H1）` 自体の展開結果も履歴に追加されます。ジャンプ（`＞` など）で別のトークに移ると、履歴はクリアされます。

```
＠色
赤
青

＊OnTest
（色）と（H1）は同じ色です。
```

## Ｃ（ループカウンタ）

繰り返しの中で、内側のカウンタが `（C0）`、その外側が `（C1）` です。ループの外では空です。
