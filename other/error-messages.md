# エラーメッセージ・警告

里々がログ（れしば・tama）に出す、主なメッセージです。辞書のミスを探すときの手がかりになります。

## 辞書の読み込み

| メッセージ | 意味・対処 |
|------------|------------|
| `カッコの対応関係が正しくない部分があります。` | 辞書に、閉じていない `（` がある。`φ（` でエスケープするか、`）` を補う |
| `is not exist.` | 辞書ファイルが見つからない（`.txt` と `.sat` のどちらも） |
| `SAORI読み込み中にエラーが発生: …` | `＠SAORI` の行に誤りがある |

## 展開の実行中

| メッセージ | 意味・対処 |
|------------|------------|
| `（名前） not found.` | 名前が見つからない。単語群・文・変数を定義しているか確認する |
| `呼び出し回数超過：名前` | `（）` の入れ子が[呼び出し回数制限](../system/vars-limits.md)を超えた（循環呼び出しなど） |
| `呼び出し総数超過（N回）：以降の呼び出しと繰り返しを打ち切ります` | 1 回のリクエストの呼び出しと繰り返しの合計が[呼び出し総数制限](../system/vars-limits.md#呼び出し総数制限)を超えた。分岐する再帰や、本体が空の長い繰り返しなどが原因（Mc201-8以降） |
| `括弧の入れ子が深すぎます（1000段まで）。` | `（）` の書き方の入れ子が[深さの上限](../system/vars-limits.md#括弧の入れ子の深さ)を超えた（Mc201-8以降） |
| `括弧展開サイズ超過：…` | 展開結果が[サイズ制限](../system/vars-limits.md)を超えた |
| `ジャンプ回数超過` | ジャンプが[回数制限](../system/vars-limits.md)を超えた |
| `繰り返しの結果が大きすぎるので、打ち切りました：N文字` | `times` `for` `while` `loop` の結果が[サイズ制限](../system/vars-limits.md#括弧展開サイズ制限)を超えた。繰り返しを打ち切った（Mc201-7以降） |
| `＄名前　添字が大きすぎます（65536未満にしてください）。` | `＄Ｒ…` `＄Ｓ…` の番号が大きすぎて、代入できなかった（[参照値](../system/names-refs.md)。Mc201-7以降） |
| `内部エラー（例外）でリクエストを中断しました: …` | 里々の内部で例外が起きたため、そのリクエストを 500 で終えた。辞書の書き方で起きたときは、直前のログを添えて報告してほしい（Mc201-7以降） |
| `＞名前 not found.` `≫名前 not found.` `≧名前 not found.` | ジャンプ先の文が見つからない（次の行から続きが実行される） |
| `式が計算不能です。` | 式の書式の誤り。カッコの数、演算子の並び、0 での除算などを確認する |
| `計算式が異常なので、無視して続行します。` | ジャンプ条件の式が計算できなかった |
| `local/Localでないので蹴りました: 名前` | 外部からのイベントで、ローカル専用の機能を呼んだ |
| `同じ名前「名前」の単語群と文があります。トラブルの元なので避けましょう。` | 文と単語群が同名。名前を変える |
| `変数「名前」と同じ名前の単語群（文）があります。…` | 変数と単語群・文が同名。名前を変える |
| `＄名前　数字のみの変数名は扱えません.` | 数字だけの変数名は使えない |
| `選択肢記法の後に文字列が存在しないので、無視して続行します。` | `＿` の行に文字列がない |

## 変数の代入行

タブも `＝` もない `＄` の行は、その場のトークに次のメッセージが出力され、そこで打ち切られます。

```
※　＄による変数代入文には、タブによる区切りか、＝による計算式が必要です　※
```

## システム変数

| メッセージ | 意味 |
|------------|------|
| `重複回避制御の方法'…' は定義されていません。` | 方法の書き間違い（[重複回避](../grammar/12-overlap-avoidance.md)） |
| `重複回避の期間'…' は定義されていません。` | 期間の書き間違い |
| `'名前' は存在しません。` | 重複回避の対象の単語群（文）がない。設定する場所が早すぎる可能性がある |
| `トーク予約、設定値がヘンです。` | `＄次からN回目のトーク` の N が 0 以下 |
| `※　乱数の指定が変です　※` | `（乱数…）` の書式の誤り |

## 内蔵関数・ssu

| メッセージ | 意味 |
|------------|------|
| `引数の個数が正しくありません。` | 引数の数が合わない |
| `引数が足りません。` | 必要な引数が足りない |
| `引数が正しくありません。` | 引数の指定が誤り |
| `命令が指定されていません` | ssu を SAORI として呼び、関数名がない |
| `Error: '名前'という名前の命令は定義されていません。` | ssu にない関数名 |
| `error: 'バイト値' : 引数が不正です。` | 引数がない |
| `split_to: 接頭辞「…」は使えません（…）。` | [split_to](../functions/split_to.md) の接頭辞に `S` `A` など、`S0` が引数・結果の値になる 1 文字を指定した |
| `error: '文の数' : 引数が不正です。` | 引数が 1 個でない |
| `forの増分に0が指定されました。` | `for` の増分が 0 |
| `error: 'execute_sstp' : コマンドを指定してください。` | [execute_sstp](../functions/execute_sstp.md) に引数がない |
| `error: '関数名' : コマンドが空です。` | `execute_sstp` のコマンドが空 |
| `error: '関数名' : コマンドや引数に改行を含めることはできません。` | `execute_sstp` `get_property` `set_property` のコマンドや引数に改行がある（送りません） |
| `'関数名' : 本体のウィンドウがまだ分からないため、送れませんでした。` | ウィンドウハンドルがまだ分からない（`（SSTP応答コード）` は `0`） |
| `'関数名' : 本体から応答がありませんでした。` | ベースウェアが 5 秒以内に応答しなかった（`（SSTP応答コード）` は `0`） |

ssu の結果としてのエラー文字列は、`（）` の展開結果としてトークに出力されます。
