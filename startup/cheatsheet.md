# チートシート

里々の書き方を 1 ページにまとめた早見表です。くわしい説明は、各項目のリンク先を見てください。

## 里々の考え方

- 辞書は**行頭の 1 文字**で意味が決まります。`＊` は文、`＠` は単語群、`＄` は代入です。
- 関数も変数も単語群も、呼び出しはすべて `（）` です。`（）` の中は、内側から順に展開されます。
- 記号は**全角**で書きます。半角の `$` や `(` は里々の記法としては働きません。
- ただし、式の中の計算用のカッコだけは半角の `(` `)` です。
- 変数の中身は、数値も含めてすべて文字列です。
- 関数の引数の区切りは、全角の `、` で書きます（`（calc、1+2）`）。

## 行頭の記号

| 書き方 | 意味 | 詳細 |
|--------|------|------|
| `＊名前` | 文（トーク）の始まり。`＊OnBoot` のようにイベント名にすると、イベントの応答になる | [文と単語群](../grammar/02-talks-and-words.md) |
| `＊`（名前なし） | ランダムトーク | [ランダムトークとタイマ](../shiori/random-talk.md) |
| `＠名前` | 単語群の始まり。**1 行が 1 単語** | [文と単語群](../grammar/02-talks-and-words.md) |
| `＊名前【タブ】式` `＠名前【タブ】式` | 採用条件式。式が真のときだけ候補になる | [採用条件式](../grammar/02-talks-and-words.md#採用条件式) |
| `＄名前【タブ】値` | 変数に文字列をそのまま代入 | [変数](../grammar/06-variables.md) |
| `＄名前＝式` | 式を計算して代入（整数は**全角**数字になる） | [式](../grammar/07-expressions.md) |
| `＞名前` | 別の文へジャンプ（戻ってこない） | [制御構造](../grammar/08-flow-control.md) |
| `＞名前【タブ】式` | 式が真のときだけジャンプ | 同上 |
| `＿ラベル【タブ】ID` | 選択肢（`\q[ラベル,ID]` になる）。後ろにタブで引数を足すと、ID の文で `（Ａ０）`〜になる | [選択肢](../grammar/09-choices.md) |
| `：` | 喋るキャラクターの切り替え（0 と 1 が交互） | [スコープとサーフェス](../grammar/10-speaker-and-surface.md) |
| `＃` | 以降はコメント | [前処理](../grammar/03-preprocess.md) |
| `φ` | 次の 1 文字をそのまま表示（`φ（` `φ）` `φ＃`） | [前処理](../grammar/03-preprocess.md#φエスケープ) |
| 行末の `φ` | 改行を打ち消して次の行と連結 | 同上 |
| `（数字）` | サーフェスの切り替え（`（0）` `（-1）`） | [スコープとサーフェス](../grammar/10-speaker-and-surface.md#サーフェスの切り替え) |
| `\` `%` で始まるもの | さくらスクリプトと置換タグ。そのまま出力 | [さくらスクリプトの扱い](../grammar/13-sakura-script.md) |

## 辞書の最小例

```
＊OnBoot
＄好感度＝（好感度）+1
：（0）こんにちは。今日は（現在曜日）曜日ですね。
：（5）（好きな色）が好きです。
＞親密なあいさつ【タブ】（好感度）>=3

＠好きな色
赤
青

＊親密なあいさつ
：また会えましたね。
```

- 文は、次の `＊` か `＠` の行の手前までです。
- 同じ名前の文や単語群を複数書くと、ランダムに 1 つが選ばれます（[重複回避](../grammar/12-overlap-avoidance.md)で偏りを調整できます）。
- 各行の終わりには、自動で `\n` が付きます（[自動挿入](../grammar/11-auto-insert.md)）。

## （）の中身

`（名前）` は、次の順に調べて最初に見つかったものになります（[名前の解決順序](../grammar/05-kakko.md#名前の解決順序)）。

| 順 | 種類 | 例 |
|----|------|----|
| 1 | 関数（`（名前、引数…）`） | `（calc、1+2）` |
| 2 | 単語群 | `（好きな色）` |
| 3 | 文 | `（初回のあいさつ）` |
| 4 | 変数・`Ｒ０` などの参照値 | `（好感度）` |
| 5 | 数字 | `（10）`（サーフェス切り替え） |
| 6 | 組み込み名 | `（現在年）` `（乱数１～６）` |
| 7 | 見つからない | `（名前）` のまま残り、ログに `not found` |

- 入れ子は内側から展開されます。`（（今日のおやつ）の説明）` は `（ケーキの説明）` になります。
- 引数の区切りは `、` `,` `､` `，` のどれか。最初に見つかった 1 種類だけが使われます。
- 引数の中の `（）` は、先にすべて展開されます。ただし特殊形式（`when` など）は、必要な引数だけを展開します。

## 変数と式

### 代入の違い

| 書き方 | `X` の値 |
|--------|----------|
| `＄X＝1+1` | `２`（全角） |
| `（set、Y、1+1）` | `2`（半角。`（set）` は式を計算しないが、数字で始まる引数は先に計算される） |
| `＄X【タブ】1+1` | `1+1`（そのまま） |
| `＄X＝`（値が空） | 変数を削除 |

- 変数がないとき、`（X）` は `（X）` のまま残ります。式の中では `０` になります。
- 存在確認は `（変数「X」の存在）`（`1` か `0`）。値がなければ `０` にするなら `（変数「X」か０）`。
- 数字だけの名前の変数は作れません。
- 変数は終了時にセーブデータへ保存されます。`今回は…` で始まる変数と `Ｓ０` は保存されません。

### 式で使える演算子

| 種類 | 演算子 |
|------|--------|
| 算術 | `+` `-` `*` `/` `%` `^` |
| 比較 | `<` `>` `<=` `>=` `==` `!=` |
| 論理 | `&&` `\|\|` `!` |
| 計算順序のカッコ | 半角の `(` `)`（全角の `（` `）` は展開に使われる） |

- 整数は 64 ビットです。小数は [calc_float](../ssu/calc_float.md) を使います。
- 0 が偽、0 以外が真です。
- 全角の `＋` `＜` `＝` なども半角として扱われます。
- `==` `!=` は文字列の比較なので、`01==1` は偽です。

式を使える場所は、`＄名前＝式`、採用条件式、`＞名前【タブ】式`、`when` `whenlist` `times` `while` `for` の引数、`calc` などです（[式](../grammar/07-expressions.md)）。

## 制御構造

| やりたいこと | 書き方 |
|--------------|--------|
| 文の候補を条件で絞る | `＊名前【タブ】式`（[採用条件式](../grammar/02-talks-and-words.md#採用条件式)） |
| 別の文へ移る（戻らない） | `＞名前` `＞名前【タブ】式` |
| 別の文を呼ぶ（戻る） | `（名前）` `（call、名前、引数…）` |
| 2 分岐 | `（when、式、真、偽）` |
| 多分岐 | `（whenlist、値、<30、冷たい、<70、ふつう、親しい）` |
| n 回繰り返す | `（times、3、（C0））` → `012` |
| 範囲で繰り返す | `（for、1、3、（C0））` → `123` |
| 条件で繰り返す | `（while、（C0）<3、（C0））` → `012` |
| 名前を呼びながら繰り返す | `（loop、名前、3）`（カウンタは `（名前カウンタ）`） |

!!! warning "when と if の違い"
    `when`（里々の特殊形式）は、選ばれた枝だけを展開します。ssu の `if` は、**両方の枝を展開してから**選びます。`（set）` などの副作用がある枝には `when` を使ってください。

!!! warning "while の無限ループ"
    `while` の条件が偽にならないと、繰り返しが止まりません。結果が `＄括弧展開サイズ制限` を超えたとき（Mc201-7以降）、または呼び出しと繰り返しの合計が `＄呼び出し総数制限`（既定 100000）を超えたとき（Mc201-8以降）に打ち切ります。

## 里々が決まったタイミングで実行する文

| 名前 | 実行されるとき |
|------|----------------|
| `＊初期化` | `satori_conf.txt` の読み込み直後。システム変数の設定を書く |
| `＊OnSatoriLoad` | 辞書の読み込み後。重複回避の設定などをここに書く |
| `＊OnSatoriBoot` | 辞書の読み込み後。結果が最初の `OnBoot` の応答になる |
| `＊OnSatoriClose` | 終了時。空でなければ終了の応答になる |
| `＊OnSatoriUnload` | アンロード直前 |
| `＊OnSatoriSecondChange` | 秒ごと。ほかに何も喋らなかったとき |
| `＊OnSatoriTimer` | `＊名前` のないタイマが発動したとき。`（Ａ０）` が名前 |
| `＊COMMUNICATE該当なし` | 話しかけられたが、該当する文がなかったとき |

イベント（`OnBoot` `OnClose` `OnMouseDoubleClick` など）は、同じ名前の文があれば実行されます（[イベントの処理](../shiori/events.md)）。マウスは `＊0Headつつかれ` のような名前の文が使われます（[デフォルトの動作](../shiori/default-behaviors.md)）。

## よく使うシステム変数

`＄名前＝値` で設定します。`有効` と書いたときだけ真で、`無効` などは偽です（[システム変数](../system/index.md)）。

| 変数 | 内容 |
|------|------|
| `＄喋り間隔＝120` | ランダムトークの間隔（秒）。0 で喋らない |
| `＄名前タイマ＝秒数` | その秒数のあとに `＊名前`（なければ `＊OnSatoriTimer`）を実行する |
| `＄次のトーク＝名前` | 次のランダムトークを予約する |
| `＄自動改行挿入＝無効` | 行末の `\n` を付けない |
| `＄自動挿入ウェイトタイプ＝無効` | 自動ウェイトを入れない（`里々` `一般` `無効`） |
| `＄今回は喋らない＝有効` | この応答では何も返さない |
| `＄単語群「名前」の重複回避＝有効、トーク中` | 同じ単語が続かないようにする |
| `＄SAORI引数の計算＝無効` | SAORI の引数を里々が先に計算しない |
| `＄デバッグ＝有効` | `ShioriEcho` などのデバッグ機能を使えるようにする |

## ハマりやすいところ

- **`satori_conf.txt` には `＊初期化` と `＠SAORI` しか書けません。** ほかの文や単語群は、読み込み後に捨てられます。辞書があることが前提の設定（重複回避など）は、`＊OnSatoriLoad` に書きます。
- **`＄X＝1+1` は全角の `２`、`（set、X、1+1）` や `（calc、1+2）` は半角です。** 全角と半角は計算では区別されませんが、`==` は文字列の比較です。
- **式の中のカッコは半角です。** 全角の `（）` は展開されます。
- **`＞` のジャンプは戻りません。** 戻りたいときは `（名前）` で呼びます。
- **`（）` の展開結果に区切り文字が入ると、引数が余分に分かれます。** 通常の関数は、先に展開してから引数に分けるためです。
- **同じ名前の文・単語群・変数を作らないでください。** 単語群、文、変数の順に見つかります。
- **タブで区切る場所があります。** `＄名前【タブ】値`、`＊名前【タブ】条件`、`＿ラベル【タブ】ID` は、タブが区切りです（半角スペースは不可）。`【タブ】` はタブ文字 1 文字の意味です（[【タブ】について](../grammar/04-script-lines.md#タブについて)）。
- **`（）` が閉じていないと、辞書の読み込みでエラーになります。** カッコの中は改行できますが、閉じ忘れに注意します。
- **`while` の無限ループは止まりません。** 条件を必ず偽にします。

## 動作確認

`＄デバッグ＝有効` にして、`ShioriEcho` でその場で試せます（[ShioriEcho とデバッグ](../shiori/debug.md)）。エラーは[エラーメッセージ・警告](../other/error-messages.md)にあります。
