# iflist

**Category:** 条件分岐

## 書式

```
（iflist、値、条件1、結果1、条件2、結果2、…、それ以外）
```

## 引数

| 引数 | 説明 |
|------|------|
| 値 | 比較される値 |
| 条件 | 比較演算子と右辺（`<10`、`>=3`、`==あ` など） |
| 結果 | 条件が真のときの結果 |
| それ以外 | 末尾に置くと、どれも真でなかったときの結果になる（省略可） |

## 戻り値

最初に真になった条件に対応する結果。どれも真にならず「それ以外」もなければ空文字列。引数が 2 個未満のときは `引数が足りません。`（エラー）。

## 解説

「値」に各「条件」を文字列として連結した式（`値<10` など）を [calc](calc.md) で順に評価し、最初に真になったものの結果を返します。数値の範囲による分岐に便利です。

## 使用例

```
（iflist、５、<3、小、<10、中、大）   → 中
（iflist、５、>10、大）            → （空）
（iflist、あ、==あ、一致）         → 一致
（iflist、（好感度）、<30、冷たい、<70、ふつう、親しい）
```
