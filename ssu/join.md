# join

**Category:** 文字列の結合

## 書式

```
（join,区切り,文字列1,文字列2,…）
```

## 引数

| 引数 | 説明 |
|------|------|
| 区切り | 要素の間に挟む文字列 |
| 文字列 | 結合する文字列（いくつでも） |

## 戻り値

結合した文字列。文字列が 1 個なら、その文字列。区切りだけのときは空文字列。引数がないときは `引数の個数が正しくありません。`（エラー）。

## 使用例

```
（join,-,a,b,c）   → a-b-c
（join,-,a）       → a
（join,-）         → （空）
```
