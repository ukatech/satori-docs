# regex_replace

**Category:** 正規表現

## 書式

```
（regex_replace、対象、パターン、置換後）
（regex_replace、対象、パターン、置換後、オプション）
```

## 引数

| 引数 | 説明 |
|------|------|
| 対象 | 検索する文字列 |
| パターン | 正規表現（[書き方](regex.md)） |
| 置換後 | 置き換える文字列。空なら取り除く |
| オプション | 省略可。`i` `s` `m` `x` の文字を並べる（[正規表現の書き方](regex.md#オプション)） |

## 戻り値

置換した後の文字列（一致がなければそのまま）。引数が足りないときは `引数の個数が正しくありません。`（エラー）。オプションに使えない文字があるときは `正規表現のオプションが正しくありません（i, s, m, x が使えます）。`（エラー）。

## 解説

一致した部分をすべて置き換えます。置換後の文字列では `$1`（グループ）`$&`（一致した部分全体）`${名前}`（名前付きグループ）`$$`（`$` 自身）などが使えます（[置換後の書き方](regex.md#置換後の書き方)）。最初の 1 か所だけなら [regex_replace_first](regex_replace_first.md) を使います。

対象の先頭が数字だと、里々が先に計算してしまうことがあります（[SAORI引数の計算](../system/vars-misc.md#saori引数の計算)）。数字で始まる文字列は、先頭に文字を付けるなどして避けてください。

Mc203-1以降。

## 使用例

先頭の数字などは、関数自身の戻り値です。

```
（regex_replace、日付2024-05-06、(\d+)-(\d+)-(\d+)、$3/$2/$1）   → 日付06/05/2024
（regex_replace、Hello hello、hello、X、i）                       → X X
（regex_replace、abc、b、[$&]）                                    → a[b]c
（regex_replace、a1、(?<n>\d)、<${n}>）                            → a<1>
```
