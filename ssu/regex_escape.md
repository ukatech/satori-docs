# regex_escape

**Category:** 正規表現

## 書式

```
（regex_escape、文字列）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文字列 | エスケープする文字列 |

## 戻り値

正規表現の特殊文字（`\ ^ $ . | ? * + ( ) [ ] { }`）の前に `\` を付けた文字列。

## 解説

文字列をそのまま（文字どおりに）パターンへ埋め込みたいときに使います。

Mc203-1以降。

## 使用例

先頭の数字などは、関数自身の戻り値です。

```
（regex_escape、a.b*c(d)）   → a\.b\*c\(d\)
```
