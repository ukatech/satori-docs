# regex_find

**Category:** 正規表現

## 書式

```
（regex_find、対象、パターン）
（regex_find、対象、パターン、オプション）
（regex_find、対象、パターン、オプション、開始位置）
```

## 引数

| 引数 | 説明 |
|------|------|
| 対象 | 検索する文字列 |
| パターン | 正規表現（[書き方](regex.md)） |
| オプション | 省略可。`i` `s` `m` `x` の文字を並べる（[正規表現の書き方](regex.md#オプション)） |
| 開始位置 | 省略可。探し始める位置（0 から数える。負なら末尾から） |

## 戻り値

最初に一致した位置（0 から数えた文字数。サロゲートペアは 1 文字）。なければ `-1`。開始位置が範囲外のときも `-1`。引数が足りないときは `引数の個数が正しくありません。`（エラー）。オプションに使えない文字があるときは `正規表現のオプションが正しくありません（i, s, m, x が使えます）。`（エラー）。

## 解説

[regex_match](regex_match.md) と同じく `（S0）`… に一致した部分とグループを入れます。位置は [at](at.md) や [substr](substr.md) と同じ数え方なので、そのまま渡せます。「オプション」を指定せずに開始位置だけ指定したいときは、オプションを空にします。

Mc203-1以降。

## 使用例

先頭の数字などは、関数自身の戻り値です。

```
（regex_find、あ😀いabc、b）          → 4
（regex_find、abcabc、c、、3）         → 5
（regex_find、abc、x）                → -1
```
