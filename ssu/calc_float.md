# calc_float

**Category:** 計算

## 書式

```
（calc_float,式）
```

## 引数

| 引数 | 説明 |
|------|------|
| 式 | 計算する式。1 個だけ指定する |

## 戻り値

計算結果。小数部の末尾の `0` と、末尾の `.` は取り除かれます。式が計算できないときは `'式' 式が計算不能です。`（エラー）。

## 解説

小数（`double`）の式を計算します。全角の数字・演算子・カッコ・全角のピリオド `．` も使えます。

使える演算子は `+ - * / ^`（`^` はべき乗、右結合。Mc201-2以降）、比較の `< > <= >= == !=`、`&& ||`、単項の `! + -` です。`%` は使えず、計算不能になります。文字列の演算はできません。

!!! warning "SAORI 引数の計算に注意"
    `＄SAORI引数の計算` が既定の「自動」だと、`5/3` のように数字で始まる引数は里々が先に整数で計算してしまい、`calc_float` には `1` が渡されます。小数の計算をするときは `＄SAORI引数の計算＝無効` にしてください。`1.5+2` のように小数を含む式は先に計算されないので、そのまま渡されます。詳しくは[ssu の引数の計算](index.md#引数の計算)を参照してください。

## 使用例

```
＄SAORI引数の計算＝無効

（calc_float,5/3）       → 1.666667
（calc_float,1.5+2）     → 3.5
（calc_float,1/4）       → 0.25
（calc_float,-0.5*4）    → -2
（calc_float,2^0.5）     → 1.414214
```
