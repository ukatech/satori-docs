# zen2han

**Category:** 変換

## 書式

```
（zen2han、文字列）
（zen2han、文字列、対象）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文字列 | 変換する文字列 |
| 対象 | 変換する種類。`アルファベット` `数字` `記号` `カナ` のうち、含まれている文字列の種類だけを変換する（省略時はすべて） |

## 戻り値

変換後の文字列。引数がないときは `引数の個数が正しくありません。`（エラー）。

## 解説

全角の文字を半角にします。

| 対象 | 変換 |
|------|------|
| アルファベット | `Ａ`〜`Ｚ` `ａ`〜`ｚ` → `A`〜`Z` `a`〜`z` |
| 数字 | `０`〜`９` → `0`〜`9` |
| 記号 | 全角の記号（`！` `＃` `（` `）` `＝` など）→ 半角。全角の空白は半角の空白になる |
| カナ | 全角カタカナ → 半角カタカナ。濁点・半濁点付きの文字は 2 文字になる（`ガ` → `ｶﾞ`） |

「対象」には `数字,記号` のように区切りを付けなくても、`数字記号` のように文字列に含まれていれば有効です。

## 使用例

```
（zen2han、ＡＢＣ１２３！）             → ABC123!
（zen2han、ＡＢＣ１２３、数字）          → ＡＢＣ123
（zen2han、ガギグ、カナ）                → ｶﾞｷﾞｸﾞ
```
