# lsimg

**Category:** その他

## 書式

```
（lsimg、フォルダ）
```

## 引数

| 引数 | 説明 |
|------|------|
| フォルダ | 画像ファイルを探すフォルダのパス |

## 戻り値

見つかったファイルの個数。ファイル名は `（S0）`、`（S1）`… に入ります（`（Sの数）` でも個数を参照できます）。フォルダが開けなかった場合や引数がない場合は `0`。

## 解説

フォルダの直下にある画像ファイルの名前を列挙します。対象の拡張子は `.png` `.jpg` `.jpe` `.jpeg` `.bmp`（大文字小文字は区別しない）です。

Windows と POSIX のビルドで動作します（POSIX は Mc203-4以降。それ以前は常に `0` を返していました）。

!!! warning "ローカルのみ"
    `SecurityLevel: local` でない呼び出し（外部から送られたイベントなど）では実行されず、`Error: 'lsimg'はlocalでないと実行できません。` が返ります（Mc201-8以降）。

## 使用例

```
（lsimg、C:\images）個の画像。1 つめは（S0）
```
