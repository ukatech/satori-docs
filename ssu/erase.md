# erase

**Category:** 置換・削除

## 書式

```
（erase、文字列、削除する文字列）
（erase、文字列、削除する文字列1、削除する文字列2、…）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文字列 | 対象の文字列 |
| 削除する文字列 | 取り除く文字列。いくつでも続けて書ける（Mc201-5以降） |

## 戻り値

取り除いた後の文字列。引数が 2 個未満のときは `引数の個数が正しくありません。`（エラー）。空の「削除する文字列」は無視されます。

## 解説

一致する部分をすべて取り除きます。最初の 1 か所だけなら [erase_first](erase_first.md) です。

「削除する文字列」を複数書いたときは、文字列を先頭から一度だけ調べて、それぞれの位置で一致したものを取り除きます。同じ位置で複数一致するときは長いほうを取り除きます。取り除いた結果、前後がつながってできた文字列は取り除きません（`（erase、aabb、ab）` は `ab` です）。

Mc201-5: 「削除する文字列」を複数書けるようにしました。

## 使用例

```
（erase、aabbaa、aa）   → bb
（erase、a,b|c:d、,、|、:）   → abcd
```

2 つ目の例で、`,` は引数の区切りと同じ文字ですが、`、` で区切って呼んでいるので 1 つの引数として渡ります。
