# han2zen

**Category:** 変換

## 書式

```
（han2zen,文字列）
（han2zen,文字列,対象）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文字列 | 変換する文字列 |
| 対象 | 変換する種類。`アルファベット` `数字` `記号` `カナ` のうち、含まれている文字列の種類だけを変換する（省略時はすべて） |

## 戻り値

変換後の文字列。引数がないときは `引数の個数が正しくありません。`（エラー）。

## 解説

半角の文字を全角にします。対応は [zen2han](zen2han.md) の逆です。半角カタカナの濁点・半濁点付き（`ｶﾞ` のように 2 文字）は 1 文字の全角（`ガ`）になります。半角の空白は全角の空白になります。

## 使用例

```
（han2zen,ABC123!ｱｶﾞ）          → ＡＢＣ１２３！アガ
（han2zen,ABC123,数字）         → ABC１２３
（han2zen,a b）                 → ａ　ｂ
```
