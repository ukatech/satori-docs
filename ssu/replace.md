# replace

**Category:** 置換・削除

## 書式

```
（replace、文字列、置換前、置換後）
（replace、文字列、置換前1、置換後1、置換前2、置換後2、…）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文字列 | 対象の文字列 |
| 置換前 | 探す文字列 |
| 置換後 | 置き換える文字列。空なら取り除く |

「置換前」と「置換後」の組は、いくつでも続けて書けます（Mc201-5以降）。

## 戻り値

置換後の文字列。「置換前」が空の組は何も置換しません。引数が 3 個未満のとき、または組になっていない（引数の個数が偶数の）ときは `引数の個数が正しくありません。`（エラー）。

## 解説

「置換前」に一致する部分をすべて置き換えます。最初の 1 か所だけを置き換えたいときは [replace_first](replace_first.md) を使います。

組を複数書いたときは、文字列を先頭から一度だけ調べて、それぞれの位置で一致した組で置き換えます。

- 置き換えた後の文字列が、ほかの組でもう一度置き換えられることはありません。`（replace、ab、a、b、b、a）` は `ba` です（順に 2 回 `replace` した場合の `aa` にはなりません）。
- 同じ位置で複数の組が一致するときは、「置換前」の長いほうを使います。`\x` と `\x[noclear]` のように、一方が他方の先頭と同じでも、書く順番を気にする必要はありません。

Mc201-5: 組を複数書けるようにしました。

## 使用例

```
（replace、aabbaa、aa、x）   → xbbx
（replace、abc、、x）        → abc
（replace、abcabc、a、1、b、2）            → 12c12c
（replace、ab、a、b、b、a）                → ba
（replace、\x[noclear]\x、\x、X、\x[noclear]、N）   → NX
（replace、abc、a、、c、）                 → b
```
