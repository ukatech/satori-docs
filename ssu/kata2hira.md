# kata2hira

**Category:** 変換

## 書式

```
（kata2hira、文字列）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文字列 | 変換する文字列 |

## 戻り値

カタカナをひらがなにした文字列。引数が 1 個でないときは `引数の個数が正しくありません。`（エラー）。

## 解説

全角カタカナを、対応するひらがなにします。カタカナ以外の文字（`ヴ` や半角カタカナ、長音 `ー` を含む）はそのままです。

## 使用例

```
（kata2hira、ひらがなカタカナ）   → ひらがなかたかな
```
