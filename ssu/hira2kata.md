# hira2kata

**Category:** 変換

## 書式

```
（hira2kata,文字列）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文字列 | 変換する文字列 |

## 戻り値

ひらがなをカタカナにした文字列。引数が 1 個でないときは `引数の個数が正しくありません。`（エラー）。

## 解説

ひらがな（小書きの `ぁぃぅぇぉゃゅょゎっ` と `ゐゑ`、濁音・半濁音を含む）を、対応する全角カタカナにします。ひらがな以外の文字はそのままです。

## 使用例

```
（hira2kata,ひらがなカタカナ）   → ヒラガナカタカナ
```
