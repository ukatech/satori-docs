# switch

**Category:** 条件分岐

## 書式

```
（switch,値,比較値1,結果1,比較値2,結果2,…,それ以外）
```

## 引数

| 引数 | 説明 |
|------|------|
| 値 | 比較される値 |
| 比較値 | 値と比べる式 |
| 結果 | 比較値と等しかったときの結果 |
| それ以外 | 末尾に置くと、どれにも一致しなかったときの結果になる（省略可） |

## 戻り値

最初に一致した比較値に対応する結果。どれにも一致せず「それ以外」もなければ空文字列。引数が 2 個未満のときは `引数が足りません。`（エラー）。

## 解説

「値」と各「比較値」を、`(値)==(比較値)` という式として [calc](calc.md) で順に評価し、最初に真になったものの結果を返します。式の評価なので、`1+1` と `2` は等しいと判定されます。文字列は文字列として比較されます。

引数の個数が偶数（値＋組の繰り返し）のときは「それ以外」なし、奇数のときは最後の 1 個が「それ以外」です。

## 使用例

```
（switch,b,a,1,b,2,他）      → 2
（switch,z,a,1,b,2,他）      → 他
（switch,z,a,1）             → （空）
（switch,1+1,1,一,2,二）     → 二
```
