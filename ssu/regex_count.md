# regex_count

**Category:** 正規表現

## 書式

```
（regex_count、対象、パターン）
（regex_count、対象、パターン、オプション）
```

## 引数

| 引数 | 説明 |
|------|------|
| 対象 | 検索する文字列 |
| パターン | 正規表現（[書き方](regex.md)） |
| オプション | 省略可。`i` `s` `m` `x` の文字を並べる（[正規表現の書き方](regex.md#オプション)） |

## 戻り値

パターンに一致した個数。引数が足りないときは `引数の個数が正しくありません。`（エラー）。オプションに使えない文字があるときは `正規表現のオプションが正しくありません（i, s, m, x が使えます）。`（エラー）。

## 解説

一致した部分の個数だけを数えます（`（S0）` などは変わりません）。[count](count.md) の正規表現版です。

Mc203-1以降。

## 使用例

先頭の数字などは、関数自身の戻り値です。

```
（regex_count、a1b22c333、\d+）   → 3
（regex_count、aaa、a）           → 3
```
