# at

**Category:** 文字列の切り出し

## 書式

```
（at,文字列,位置）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文字列 | 対象の文字列 |
| 位置 | 取り出す文字の位置（0 から数える） |

## 戻り値

その位置の 1 文字。位置が文字数以上のときは空文字列。引数が 2 個でないときは `引数が正しくありません。`（エラー）。

## 解説

サロゲートペアの文字は 1 文字として数えます。位置に負数を指定した場合は 0 と同じ扱いになります（末尾から数えることはできません）。

## 使用例

```
（at,あいう,1）   → い
（at,あいう,0）   → あ
（at,あいう,5）   → （空）
```
