# is_digit

**Category:** 比較・判定

## 書式

```
（is_digit,文字列）
（is_digit,文字列,整数）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文字列 | 調べる文字列 |
| 整数 | 指定すると小数点を認めない。`整数` を含む文字列、`int`、`integer` のいずれか |

## 戻り値

数値として読める文字列なら `1`、そうでなければ `0`。引数がない、または空文字列のときは `0`。

## 解説

- 先頭に符号（`+` `-` と全角の `＋` `−`）を 1 つ付けられます。符号だけの文字列は `0` です。
- 数字は全角でも半角でもかまいません。
- 小数点（`.` と全角の `．`）は 1 つだけ認めます。「整数」を指定すると認めません。
- 指数表記（`1e5`）や 3 桁区切り（`1,000`）は数値として認めません。

## 使用例

```
（is_digit,123）        → 1
（is_digit,１２３）     → 1
（is_digit,-1.5）       → 1
（is_digit,1.5,整数）   → 0
（is_digit,1.2.3）      → 0
（is_digit,abc）        → 0
（is_digit,-）          → 0
```
