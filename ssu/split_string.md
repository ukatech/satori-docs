# split_string

**Category:** 文字列の分割

## 書式

```
（split_string,文字列）
（split_string,文字列,区切り文字列）
（split_string,文字列,区切り文字列,最大個数）
（split_string,文字列,区切り文字列,最大個数,空要素を残す）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文字列 | 分割する文字列 |
| 区切り文字列 | 区切りにする文字列。並びが一致した部分で分割する |
| 最大個数 | 分割後の要素数の上限（省略または 0 で無制限） |
| 空要素を残す | 0 以外なら、区切りが連続してできた空の要素も残す（既定は残さない） |

## 戻り値

要素の個数。結果の要素は `（S0）`、`（S1）`… に入り、個数は `（Sの数）` でも参照できます。引数がないときは `引数の個数が正しくありません。`（エラー）。

## 解説

[split](split.md) と違い、「区切り文字列」全体が一致した部分だけで分割します。区切り文字列を省略した場合、または空の場合は、文字列を 1 文字ずつに分割します。

「最大個数」に達したときの最後の要素は、区切り文字列の直後から残り全部です（`（split_string,a->b->c,->,2）` の `S1` は `b->c`）。Mc201-1 では、2 文字以上の区切り文字列のとき先頭に区切りの 2 文字目以降が残る不具合がありました（Mc201-2 で修正）。

## 使用例

```
（split_string,a--b--c,--）（S0）/（S1）/（S2）   → a/b/c
（split_string,あ、い、う,、）（Sの数）           → 3
（split_string,a->b->c,->,2）（S0）/（S1）      → a/b->c
```
