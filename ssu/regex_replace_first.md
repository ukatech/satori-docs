# regex_replace_first

**Category:** 正規表現

## 書式

```
（regex_replace_first、対象、パターン、置換後）
（regex_replace_first、対象、パターン、置換後、オプション）
```

## 引数

| 引数 | 説明 |
|------|------|
| 対象 | 検索する文字列 |
| パターン | 正規表現（[書き方](regex.md)） |
| 置換後 | 置き換える文字列 |
| オプション | 省略可。`i` `s` `m` `x` の文字を並べる（[正規表現の書き方](regex.md#オプション)） |

## 戻り値

置換した後の文字列。引数が足りないときは `引数の個数が正しくありません。`（エラー）。オプションに使えない文字があるときは `正規表現のオプションが正しくありません（i, s, m, x が使えます）。`（エラー）。

## 解説

最初に一致した 1 か所だけを置き換えます。置換後の文字列では `$1`（グループ）`$&`（一致した部分全体）`${名前}`（名前付きグループ）`$$`（`$` 自身）などが使えます（[置換後の書き方](regex.md#置換後の書き方)）。

Mc203-1以降。

## 使用例

先頭の数字などは、関数自身の戻り値です。

```
（regex_replace_first、aaa、a、b）   → baa
```
