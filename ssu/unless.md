# unless

**Category:** 条件分岐

## 書式

```
（unless,式,偽のとき,真のとき）
（unless,式,偽のとき）
```

## 引数

| 引数 | 説明 |
|------|------|
| 式 | [calc](calc.md) と同じ規則で計算する式 |
| 偽のとき | 式の結果が 0 のときの結果 |
| 真のとき | 式の結果が 0 以外のときの結果（省略可） |

## 戻り値

式が偽なら「偽のとき」、真なら「真のとき」。真で「真のとき」がなければ空文字列。引数が 2〜3 個でないときは `引数の個数が正しくありません。`（エラー）。

## 解説

[if](if.md) の真偽を逆にしたものです。

## 使用例

```
（unless,（好感度）>=50,まだ仲良しではない,仲良し）
```
