# regex_split

**Category:** 正規表現

## 書式

```
（regex_split、対象、パターン）
（regex_split、対象、パターン、オプション）
（regex_split、対象、パターン、オプション、最大個数）
```

## 引数

| 引数 | 説明 |
|------|------|
| 対象 | 検索する文字列 |
| パターン | 区切りにする正規表現 |
| オプション | 省略可。`i` `s` `m` `x` の文字を並べる（[正規表現の書き方](regex.md#オプション)） |
| 最大個数 | 省略または 0 で無制限。上限に達したら、残りは 1 つの要素にまとまる |

## 戻り値

要素の個数。結果は `（S0）`、`（S1）`… に入り、個数は `（Sの数）` でも参照できます。引数が足りないときは `引数の個数が正しくありません。`（エラー）。オプションに使えない文字があるときは `正規表現のオプションが正しくありません（i, s, m, x が使えます）。`（エラー）。

## 解説

一致した部分で区切って分割します。[split](split.md) と違って空の要素も残ります。パターンが空なら 1 文字ずつに分割します。先頭・末尾にある空文字列への一致では区切りません。括弧のグループは結果に入りません。

Mc203-1以降。

## 使用例

先頭の数字などは、関数自身の戻り値です。

```
（regex_split、a, b,c ,d、\s*,\s*）（S0）/（S1）/（S2）/（S3）   → 4a/b/c/d
（regex_split、a,b,c,d、,、、2）（S0）/（S1）               → 2a/b,c,d
（regex_split、abc、）（S0）/（S1）/（S2）                    → 3a/b/c
```
