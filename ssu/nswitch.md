# nswitch

**Category:** 条件分岐

## 書式

```
（nswitch、n、候補1、候補2、候補3、…）
```

## 引数

| 引数 | 説明 |
|------|------|
| n | 何番目の候補を返すか（1 から数える） |
| 候補 | 選択肢 |

## 戻り値

n 番目の候補。n が 0 以下、または候補の数より大きいときは空文字列。引数が 2 個未満のときは `引数が足りません。`（エラー）。

## 解説

番号で候補を選びます。番号は 1 から始まります。

## 使用例

```
（nswitch、2、a、b、c）   → b
（nswitch、0、a、b）     → （空）
（nswitch、3、a、b）     → （空）
（nswitch、（乱数1～3）、朝、昼、夜）
```
