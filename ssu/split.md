# split

**Category:** 文字列の分割

## 書式

```
（split、文字列）
（split、文字列、区切り文字）
（split、文字列、区切り文字、最大個数）
（split、文字列、区切り文字、最大個数、空要素を残す）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文字列 | 分割する文字列 |
| 区切り文字 | 区切りにする文字を並べたもの。**1 文字ずつがそれぞれ区切り**になる（`-,` なら `-` も `,` も区切り） |
| 最大個数 | 分割後の要素数の上限（省略または 0 で無制限）。上限に達したら、残りは 1 つの要素にまとまる |
| 空要素を残す | 0 以外なら、区切りが連続してできた空の要素も残す（既定は残さない） |

## 戻り値

要素の個数。結果の要素は `（S0）`、`（S1）`… に入り、個数は `（Sの数）` でも参照できます。引数がないときは `引数の個数が正しくありません。`（エラー）。

## 解説

- 「区切り文字」を省略した場合、または空の場合は、文字列を 1 文字ずつに分割します。
- 空の要素は、「空要素を残す」を指定しない限り捨てられます。
- 「区切り文字」を文字列として（並びのまま）区切りにしたいときは [split_string](split_string.md) を使います。
- `（S0）` などを上書きせずに、指定した名前の変数に結果を入れたいときは、内蔵関数の [split_to](../functions/split_to.md) を使います（Mc201-5以降）。

## 使用例

先頭の数字は、関数自身の戻り値（要素の個数）です。

```
（split、a-b-c-d、-）（S0）/（S1）/（S2）/（S3）   → 4a/b/c/d
（split、a-b--c、-、0、1）（Sの数）                  → 44  （S2 は空）
（split、a-b-c-d、-、2）（S0）/（S1）               → 2a/b-c-d
（split、あいう）（Sの数）                        → 33  （1 文字ずつ）
```
