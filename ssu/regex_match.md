# regex_match

**Category:** 正規表現

## 書式

```
（regex_match、対象、パターン）
（regex_match、対象、パターン、オプション）
```

## 引数

| 引数 | 説明 |
|------|------|
| 対象 | 検索する文字列 |
| パターン | 正規表現（[書き方](regex.md)） |
| オプション | 省略可。`i` `s` `m` `x` の文字を並べる（[正規表現の書き方](regex.md#オプション)） |

## 戻り値

対象の中にパターンに一致する部分があれば `1`、なければ `0`。引数が足りないときは `引数の個数が正しくありません。`（エラー）。オプションに使えない文字があるときは `正規表現のオプションが正しくありません（i, s, m, x が使えます）。`（エラー）。

## 解説

「対象」のどこかがパターンに一致するか調べます（全体が一致する必要はありません。全体の一致を調べたいときは `^` と `$` で挟みます）。

一致したときは、結果を `（S0）`、`（S1）`… に入れます。`（S0）` が一致した部分全体、`（S1）` 以降が括弧のグループです（一致しなかったグループは空）。名前付きグループの番号は[正規表現の書き方](regex.md#グループの番号)を参照してください。

Mc203-1以降。

## 使用例

先頭の数字などは、関数自身の戻り値です。

```
（regex_match、abc123def、(\d+)）（S0）/（S1）   → 1123/123
（regex_match、abc、(\d+)）                      → 0
（regex_match、ABC、b、i）（S0）                  → 1B
（regex_match、abc、^b）                          → 0
```
