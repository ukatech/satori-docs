# if

**Category:** 条件分岐

## 書式

```
（if、式、真のとき、偽のとき）
（if、式、真のとき）
```

## 引数

| 引数 | 説明 |
|------|------|
| 式 | [calc](calc.md) と同じ規則で計算する式 |
| 真のとき | 式の結果が 0 以外のときの結果 |
| 偽のとき | 式の結果が 0 のときの結果（省略可） |

## 戻り値

式が真なら「真のとき」、偽なら「偽のとき」。偽で「偽のとき」がなければ空文字列。引数が 2〜3 個でないときは `引数の個数が正しくありません。`（エラー）、式が計算できないときは `'式' 式が計算不能です。`（エラー）。

## 解説

式の結果を数値として見て、0 以外なら真として扱います。

`（）` の中の引数は先に展開されてから渡されるため、真・偽の両方の枝の `（）` が実行されます。片方だけを実行したいときは、特殊形式の [when](../functions/when.md) を使います。

## 使用例

```
（if、（好感度）>=50、仲良し、ふつう）
（if、（calc、1+1）==2、正しい）
```
