# regex_findall

**Category:** 正規表現

## 書式

```
（regex_findall、対象、パターン）
（regex_findall、対象、パターン、オプション）
```

## 引数

| 引数 | 説明 |
|------|------|
| 対象 | 検索する文字列 |
| パターン | 正規表現（[書き方](regex.md)） |
| オプション | 省略可。`i` `s` `m` `x` の文字を並べる（[正規表現の書き方](regex.md#オプション)） |

## 戻り値

一致した個数。引数が足りないときは `引数の個数が正しくありません。`（エラー）。オプションに使えない文字があるときは `正規表現のオプションが正しくありません（i, s, m, x が使えます）。`（エラー）。

## 解説

一致した部分すべてを、前から順に `（S0）`、`（S1）`… に入れます（括弧のグループではなく、一致した部分全体）。空文字列に一致するパターンは 1 文字ずつ進みます。

Mc203-1以降。

## 使用例

先頭の数字などは、関数自身の戻り値です。

```
（regex_findall、a1b22c333、\d+）（S0）/（S1）/（S2）   → 31/22/333
```
