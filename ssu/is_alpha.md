# is_alpha

**Category:** 比較・判定

## 書式

```
（is_alpha,文字列）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文字列 | 調べる文字列 |

## 戻り値

すべて英字（`A`〜`Z`、`a`〜`z`、全角の `Ａ`〜`Ｚ`、`ａ`〜`ｚ`）なら `1`、そうでなければ `0`。引数がない、または空文字列のときは `0`。

## 使用例

```
（is_alpha,abcＸ）   → 1
（is_alpha,ab1）     → 0
（is_alpha,あ）      → 0
```
