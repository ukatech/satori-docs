# count

**Category:** 置換・削除・数え上げ

## 書式

```
（count、対象1、対象2、…、探す文字列）
```

## 引数

| 引数 | 説明 |
|------|------|
| 対象 | 探される文字列（いくつでも） |
| 探す文字列 | 最後の引数。出現回数を数える文字列 |

## 戻り値

「探す文字列」が全ての「対象」の中に現れた回数の合計。引数がないときは `引数の個数が正しくありません。`（エラー）。引数が 1 個のときは `0`。

## 解説

最後の引数が「探す文字列」で、それより前の引数はすべて「対象」として扱われます。重なる部分は数えません（`abababa` の中の `aba` は 2 回）。

!!! warning "全角数字を数えるとき"
    探す文字列が全角数字だけ（`１` など）だと、里々が先に半角へ変えるので、全角の数字は数えられません。`＄SAORI引数の計算＝無効` にするか、[regex_count](regex_count.md) でパターンを `[１]` のように書いてください（対象が全角数字だけのときは、後者は使えません）。詳しくは[ssu の引数の計算](index.md#全角数字だけの引数)を参照してください。

## 使用例

```
（count、abababa、aba）   → 2
（count、abab、ab、b）     → 3   （abab の中の b が 2 回 + ab の中の b が 1 回）
（count、abc）           → 0
（count、１１bbbb、１）   → 0   （１ が半角の 1 に変わるため）
```

`＄SAORI引数の計算＝無効` にすると、全角の数字を数えられます。

```
＄SAORI引数の計算＝無効

（count、１１bbbb、１）   → 2
```
