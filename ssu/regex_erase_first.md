# regex_erase_first

**Category:** 正規表現

## 書式

```
（regex_erase_first、対象、パターン）
（regex_erase_first、対象、パターン、オプション）
```

## 引数

| 引数 | 説明 |
|------|------|
| 対象 | 検索する文字列 |
| パターン | 正規表現（[書き方](regex.md)） |
| オプション | 省略可。`i` `s` `m` `x` の文字を並べる（[正規表現の書き方](regex.md#オプション)） |

## 戻り値

取り除いた後の文字列。引数が足りないときは `引数の個数が正しくありません。`（エラー）。オプションに使えない文字があるときは `正規表現のオプションが正しくありません（i, s, m, x が使えます）。`（エラー）。

## 解説

最初に一致した 1 か所だけを取り除きます。

Mc203-1以降。

## 使用例

先頭の数字などは、関数自身の戻り値です。

```
（regex_erase_first、a1b2c3、\d）   → ab2c3
```
