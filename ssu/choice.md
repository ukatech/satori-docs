# choice

**Category:** その他

## 書式

```
（choice、候補1、候補2、候補3、…）
```

## 引数

| 引数 | 説明 |
|------|------|
| 候補 | 選択肢（いくつでも） |

## 戻り値

候補の中からランダムに選んだ 1 つ。候補がないときは空文字列。

## 解説

すべての候補が等しい確率で選ばれます。重複回避は行われません。重複を避けたいときは単語群（`＠`）と[重複回避](../grammar/12-overlap-avoidance.md)を使います。

## 使用例

```
（choice、朝、昼、夜）
```
