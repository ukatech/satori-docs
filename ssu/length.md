# length

**Category:** 比較・判定

## 書式

```
（length、文字列）
```

## 引数

| 引数 | 説明 |
|------|------|
| 文字列 | 文字数を数える文字列 |

## 戻り値

文字数。引数がない、または空文字列のときは `0`。

## 解説

文字単位で数えます。全角・半角の区別はなく、どちらも 1 文字です。サロゲートペアの文字は 1 文字です。

## 使用例

```
（length、あいう）   → 3
（length、abc）      → 3
（length、😀）       → 1
```
